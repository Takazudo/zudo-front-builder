zudo-wind は zfb が提供する独自のユーティリティ CSS エンジンです。バージョン管理された有限の v1 言語に沿って、ソース内のクラス候補から CSS を生成します。色パレット、余白の単位、名前付きスケールは組み込まれず、トークンはプロジェクトで明示的に設定します。以下のページでは、設定、言語仕様、カスケード、Tailwind からの移行を扱います。
