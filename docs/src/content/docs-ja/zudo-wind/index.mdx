zudo-wind はプロジェクトのソースに記述された完全なクラス候補から、バージョン管理された CSS を生成します。値はプロジェクトが選びます。v1 にはデフォルトのパレット、余白単位、名前付きスケール、ブレークポイントはありません。

## 用途から始める

- [最初のコンポーネントを設定する](./overview.mdx) — 値を明示し、完全なクラス候補を使います。
- [色、余白、その他の値を定義する](./tokens.mdx)。
- [候補の綴りと任意値を確認する](./utility-grammar.mdx)。
- [レスポンシブ、ダーク、状態、関係、疑似要素の条件を使う](./variants.mdx)。
- 対応クラスと CSS の動作は[全ユーティリティ一覧](./utilities/index.mdx)を参照してください。

[設定ガイド](./configuration.mdx)ではソースの発見方法とコンパイラ設定を説明します。[Tailwind からの移行](./coming-from-tailwind.mdx)では変更された構文と移行方法を確認できます。
