zudo-wind は zfb が提供するユーティリティ CSS エンジンです。バージョン管理された v1 言語が、プロジェクトのソース内にある有限のクラス候補から CSS を生成します。トークンはプロジェクトが用意します。色パレット、余白単位、名前付きスケールはデフォルトでは含まれません。以下のページでは、設定、言語の文法、カスケード、Tailwind からの移行を説明します。
