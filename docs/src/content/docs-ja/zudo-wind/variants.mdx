## 利用できるバリアント

v1 では、設定済みのレスポンシブブレークポイント、任意のダークモード、名前のない group と peer の関係、`open` を含む 9 つの要素状態、5 つの疑似要素を使えます。候補には各カテゴリから最大 1 つのバリアントを指定できます。正規順は次のとおりです。

    responsive → dark → relation → state → pseudo-element → utility

レスポンシブとダークのバリアントは、それぞれ最大 1 つです。関係と自身の状態はそれぞれ 1 つ指定でき、関係バリアント自体も group または peer 上の状態を示します。同じバリアントは繰り返せません。最小幅と最大幅を組み合わせる形式はありません。

## レスポンシブとダークのバリアント

ブレークポイントは、`minWidthPx` に正の整数を持つ設定済みの名前です。640 に設定した `sm` は、CSS ピクセルで最小幅 640 のメディア条件を意味します。`max-sm` は排他的な条件 `width < 640px` を使い、微小値を引きません。ピクセル幅はルートのフォントサイズが変わっても固定です。

ダークモードはデフォルトで無効です。小文字の属性名と空でない値を設定すると `dark` を有効にできます。条件は要素自身かいずれかの祖先にその属性がある場合に一致します。生成セレクタは `:where(...)` を使うため、ダークモードによる詳細度の加算はゼロです。値は CSS 文字列としてエスケープされます。

## 関係と状態のバリアント

自身に適用できる状態を正規の順位で示します。

| 順位 | バリアント | セレクタの動作 |
| --- | --- | --- |
| 1 | `first` | `:first-child` |
| 2 | `last` | `:last-child` |
| 3 | `open` | `:is([open], :popover-open)` |
| 4 | `focus-within` | `:focus-within` |
| 5 | `hover` | `:hover` |
| 6 | `focus` | `:focus` |
| 7 | `focus-visible` | `:focus-visible` |
| 8 | `active` | `:active` |
| 9 | `disabled` | `:disabled` |

状態がない場合の順位は 0 です。表には 1～9 を載せています。ほかの状態セレクタは、状態名を疑似クラスとして使います。group と peer を含むすべての hover 状態には、`@media (hover: hover)` のガードが付きます。

`group` マーカーは祖先に置きます。`peer` マーカーは前の兄弟要素に置く必要があります。group の状態は `:where(.group:S) C`、peer の状態は `:where(.peer:S) ~ C` を使います。`C` はエスケープされた候補セレクタ、`S` は選択した状態です。関係セレクタによる詳細度の加算はゼロです。関係なしは順位 0、group の状態は 1～9、peer の状態は 10～18 で、それぞれ状態順に並びます。`group/menu` や `group-hover/menu:block` のような名前付きマーカーと関係形式は未対応です。

## 疑似要素

利用できる疑似要素は `before`、`after`、`marker`、`placeholder`、`backdrop` です。この順に順位 1～5 を持ち、状態セレクタの後に追加されます。順位 0 は疑似要素なしです。`before` と `after` は `content` 宣言を挿入しません。必要なら手書きの CSS に宣言を追加してください。

## 順序と拒否

完全な連鎖の順序はレスポンシブ、ダーク、関係、状態、疑似要素、ユーティリティです。たとえば `sm`、ダークモード、`colors.panel` が設定されていれば `sm:dark:hover:bg-panel` は正規の順序です。`hover:sm:block` は順序が違うため ZW003 になり、並べ替えた `sm:hover:block` が提案されます。重複や未知のバリアントには、自動の並べ替え提案はありません。

セレクタは元の完全な候補からエスケープして作ります。ダークモードを `data-theme="dark"` に設定した場合、`dark:hover:bg-panel` のセレクタは次のとおりです。

    .dark\:hover\:bg-panel:where([data-theme="dark"], [data-theme="dark"] *):hover

レスポンシブと hover の条件は `and` で 1 つのメディアラッパーにまとめます。ダーク条件はセレクタ内に残ります。`first` と `last` は子の位置に対応し、`open` は開いたポップオーバーも認識します。

v1 では `aria-*` と `data-*` の属性バリアント、任意セレクタのバリアント、ダークモードが無効なときの `dark` を ZW004 で拒否します。これらのセレクタは手書きの CSS に記述してください。疑似要素バリアントと子要素間の余白や区切り線のユーティリティを組み合わせると、子セレクタが疑似要素の子を指してしまうため R23/ZW005 で拒否されます。
