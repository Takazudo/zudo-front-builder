文字と文字の間隔を調整します。短い見出しでは少し詰めたり広げたりできますが、長い文章には標準的で読みやすい間隔が向いています。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `tracking-tight` | `letter-spacing: var(--zw-tracking-tight);` |
| `tracking-[0.12em]` | `letter-spacing: 0.12em;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。各例は tokens.letterSpacings を宣言します。wind-demo は枠、折り返しの安全策、ラベル、色だけを設定し、文字間隔は tracking クラスが決めます。

</Details>

## 任意値と名前付きの値

tracking-tight は tokens.letterSpacings.tight を参照します。負の値で文字を詰めることもできます。tracking-[0.12em] のような任意値は letter-spacing の CSS として検証されます。広い字間は段落や日本語を読みにくくすることがあるため、短いラベルや意図した表示に限って使うとよいでしょう。

## tracking

| --- | --- |
| カタログ識別子 | `v1.tracking` |
| クラスパターン | `tracking-<suffix>` |
| 文法 | `{"acceptedKinds":["token","arbitrary"],"arbitraryProperty":"letter-spacing","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | この項目には独立した値の定義がありません。 |
| トークンカテゴリ | `letterSpacings` |
| 負の値の規則 | `allowed` |
| 競合グループと順位 | `tracking` (`19`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `letter-spacing` |

### 受け入れる値

この項目には独立した値の定義がありません。
