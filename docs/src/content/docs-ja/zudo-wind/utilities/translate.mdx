## translate-x

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.translate.x` |
| クラスパターン | `translate-x-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","scale","fraction","arbitrary"],"arbitraryProperty":"translate","allowsFractionSlash":true,"allowsColorOpacity":false}` |
| 受け入れる値 | `2` |

| 負の値の規則 | `allowed` |
| 競合グループと順位 | `translate` (`38`) |

| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `--zw-translate-x`, `translate` |
