レイアウト上の占有領域を変えずに、要素を水平方向または垂直方向へ移動します。同じ要素上で二つの軸を合成できます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `translate-x-8` | `--zw-translate-x: 2rem; translate: var(--zw-translate-x) var(--zw-translate-y);` |
| `translate-y-4` | `--zw-translate-y: 1rem; translate: var(--zw-translate-x) var(--zw-translate-y);` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。これにより translate-x-8 は 2rem、translate-y-4 は 1rem になります。一つの例では名前付き間隔 rail に 2rem を設定します。図のステージ、基準位置、四角形だけを自作 CSS で描き、移動と回転は zudo-wind のユーティリティで指定します。

</Details>

## 任意値と名前付きの値

数値の接尾辞には、設定した tokens.spacingUnit を使います。translate-x-rail のような名前付きの値は tokens.spacing から参照します。translate-y-1/2 のような分数は要素の寸法に対する割合で、角括弧内には個別の CSS 長さを指定できます。固定値 0 と full はそれぞれ 0 と 100% です。負の値も使えます。Tailwind の間隔スケールは継承しません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## translate-x

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.translate.x` |
| クラスパターン | `translate-x-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","scale","fraction","arbitrary"],"arbitraryProperty":"translate","allowsFractionSlash":true,"allowsColorOpacity":false}` |
| 受け入れる値 | `3` |
| トークンカテゴリ | `spacing` |
| 負の値の規則 | `allowed` |
| 競合グループと順位 | `translate` (`38`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `--zw-translate-x`, `translate` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"0"` | `"0"` |
| `keyword` | `"px"` | `"1px"` |
| `keyword` | `"full"` | `"100%"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `--zw-translate-x` | `resolved` | `null` |
| `translate` | `fixed` | `"var(--zw-translate-x) var(--zw-translate-y)"` |
