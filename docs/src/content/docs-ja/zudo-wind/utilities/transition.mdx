状態や値が変わったときに滑らかに変化させる CSS プロパティを選びます。hover や focus-visible などの状態バリアントと、実際に操作できる要素に組み合わせます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `transition-colors` | `transition-property: color,background-color,border-color,outline-color,text-decoration-color,fill,stroke; transition-duration: 150ms; transition-timing-function: ease;` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。transition-none 以外のトランジション系ユーティリティは 150ms と設定済みのタイミング関数を使います。ボタンはポインターの hover とキーボードの focus の両方に反応します。prefers-reduced-motion が reduce の場合は、自作デモ CSS が時間を 0 にします。ユーティリティの例は短く、操作したときだけ変化します。

</Details>

## 任意値と名前付きの値

使えるキーワードは transition、transition-all、transition-colors、transition-opacity、transition-shadow、transition-transform、transition-none です。transition-[border-color] のように任意のプロパティリストも指定できます。組み込みの名前付き transition-property トークンはありません。transition-none は transition-property: none だけを出力し、時間やイージングの初期値は設定しません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## transition

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.transition` |
| クラスパターン | `transition` or `transition-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","arbitrary"],"arbitraryProperty":"transition-property","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `7` |
| トークンカテゴリ | トークンカテゴリなし |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `transition` (`35`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `transition-property`, `transition-duration`, `transition-timing-function` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `null` | `"all"` |
| `keyword` | `"all"` | `"all"` |
| `keyword` | `"none"` | `"none"` |
| `keyword` | `"colors"` | `"color,background-color,border-color,outline-color,text-decoration-color,fill,stroke"` |
| `keyword` | `"opacity"` | `"opacity"` |
| `keyword` | `"shadow"` | `"box-shadow"` |
| `keyword` | `"transform"` | `"transform,translate,rotate,scale"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `transition-property` | `resolved` | `null` |
| `transition-duration` | `transitionDuration` | `null` |
| `transition-timing-function` | `transitionTimingFunction` | `null` |
