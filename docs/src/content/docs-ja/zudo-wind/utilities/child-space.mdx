space-x と space-y は、親要素の後続する対象の子要素に margin を追加します。子要素は親の直下に並ぶ必要があります。親の padding やレイアウトトラック間の gap は設定しません。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `space-x-4` | `margin-left: 1rem;` |
| `space-y-3` | `margin-top: 0.75rem;` |

<Details title={"例の設定"}>

この例では spacingUnit: "0.25rem"、reset: "none"、strict モード、空のブレークポイントを明示しています。space-x は対象となる後続の兄弟要素に margin-left、space-y は margin-top を追加します。Tailwind のスケールやテーマは継承しません。wind-demo クラスはカードと枠の表示だけを担当し、自作 CSS は各プレビューから確認できます。

</Details>

## 任意値と名前付きの値

space-x-0 と space-y-0 は margin を追加せず、px 接尾辞は 1px を表します。それ以外の数値には tokens.spacingUnit、名前付きの値には tokens.spacing が必要です。space-y-[18px] のような角括弧の値では、一度だけ使う長さを指定できます。負の値も使え、-space-x-2 で項目を近づけたり重ねたりできます。子セレクターは hidden 属性のある兄弟要素を除外します。計算後の display は調べないため、hidden 属性がない display:none の要素は対象になります。対象は DOM の兄弟順です。このユーティリティは margin の省略形なので、grid、折り返すレイアウト、視覚上の順番を反転したレイアウトには gap を使い、子ごとに異なる間隔には個別の margin を使います。
