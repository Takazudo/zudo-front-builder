position で、オフセットの基準と通常フローへの残り方を選びます。relative は場所を保ったまま absolute 子要素の基準になり、absolute はフローから外れます。fixed はプレビューのビューポートに固定され、sticky はスクロール領域の中で端に張り付きます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `static` | `position: static;` |
| `relative` | `position: relative;` |
| `absolute` | `position: absolute;` |
| `sticky` | `position: sticky;` |
| `fixed` | `position: fixed;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

5 個のクラス名は固定で、値は付きません。top-4 などのオフセットは位置指定された箱だけを動かし、static は無視して、absolute 子要素の基準にもなりません。sticky には auto 以外の inset 閾値とスクロール領域が必要です。CSS では transform の祖先が fixed 子要素の包含ブロックになることもあります。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
