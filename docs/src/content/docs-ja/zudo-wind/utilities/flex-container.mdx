これらのユーティリティは flex コンテナに指定します。direction は主軸と項目の順序を決め、wrap は1行のままにするか次の行へ送るかを決めます。横並びには row、操作項目やカードの縦積みには column を使います。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `flex-row` | `flex-direction: row;` |
| `flex-row-reverse` | `flex-direction: row-reverse;` |
| `flex-col` | `flex-direction: column;` |
| `flex-col-reverse` | `flex-direction: column-reverse;` |
| `flex-wrap` | `flex-wrap: wrap;` |
| `flex-nowrap` | `flex-wrap: nowrap;` |
| `flex-wrap-reverse` | `flex-wrap: wrap-reverse;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

7 個のクラス名は固定で、値の接尾辞はありません。flex-row と flex-col が方向を選び、reverse 形は見た目の順序を逆にします。flex-wrap、flex-nowrap、flex-wrap-reverse が折り返し方を決めます。これらは flex コンテナを作らないため、別途 display:flex が必要です。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
