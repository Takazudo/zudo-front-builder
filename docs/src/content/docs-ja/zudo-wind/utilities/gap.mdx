グリッドやフレックスのコンテナに gap を指定して、項目の間隔を作ります。コンテナの内側の余白ではなく、トラックや項目の間に空間を追加します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `gap-4` | `column-gap: 1rem; row-gap: 1rem;` |
| `gap-x-8` | `column-gap: 2rem;` |
| `gap-y-2` | `row-gap: 0.5rem;` |
| `gap-gutter` | `column-gap: var(--zw-spacing-gutter); row-gap: var(--zw-spacing-gutter);` |
| `gap-[18px]` | `column-gap: 18px; row-gap: 18px;` |

<Details title={"例の設定"}>

この例では spacingUnit: "0.25rem"、reset: "none"、strict モード、空のブレークポイントを明示しています。数値の接尾辞に単位を掛けるため、gap-4 は 1rem の長さを直接出力します。Tailwind のスケールやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、各プレビューから CSS を確認できます。

</Details>

## 任意値と名前付きの値

gap-0 は間隔をなくし、gap-px はトークンなしで 1px を指定します。それ以外の数値には tokens.spacingUnit が必要です。gutter の例のような名前付きの値は tokens.spacing で設定します。gap-[18px] などの任意値はスケール不要です。負の間隔は使えません。任意値の calc 内の空白はアンダースコアで表します。gap-x は column-gap、gap-y は row-gap を設定します。フレックスでは、項目間と行間への作用は flex-direction に従います。

## gap

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.gap` |
| クラスパターン | `gap-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","scale","arbitrary"],"arbitraryProperty":"column-gap","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `spacing` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `gap` (`11`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `column-gap`, `row-gap` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"0"` | `"0"` |
| `keyword` | `"px"` | `"1px"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `column-gap` | `resolved` | `null` |
| `row-gap` | `resolved` | `null` |

### カタログの例

| クラスの例 | 期待される宣言 |
| --- | --- |
| `gap-0` | `column-gap: 0`; `row-gap: 0` |
