要素に適用するフォントファミリーを選びます。サイト内で繰り返し使うスタックは名前付きトークンにし、その場限りの指定には任意値を使います。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `font-ui` | `font-family: var(--zw-font-family-ui);` |
| `font-[Georgia,_serif]` | `font-family: Georgia, serif;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。トークンを使う各例では tokens.fontFamilies をレコード内に記述します。ブラウザーや Tailwind のテーマは前提にしません。wind-demo クラスは余白、枠、ラベル、色だけを加え、フォントユーティリティが書体を指定します。

</Details>

font-[Georgia,_serif] はアンダースコアを空白に戻して Georgia, serif として解決します。プレビューを独立させるため、トークン設定もこの例に記述しています。

## 任意値と名前付きの値

font-reading は tokens.fontFamilies.reading を参照します。font-family と font-weight は同じ font ルートを使うため、ひとつの設定内で名前が重ならないようにします。font-[Georgia,_serif] のような任意値ではアンダースコアが空白になり、font-family の値として検証されます。複数箇所で使うスタックは名前付きトークンにし、局所的な例外には任意値を使うと管理しやすくなります。指定したフォントはアプリ側で読み込まれている必要があります。

## font

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.font.family` |
| クラスパターン | `font-<suffix>` |
| 文法 | `{"acceptedKinds":["token","arbitrary"],"arbitraryProperty":"font-family","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | この項目には独立した値の定義がありません。 |
| トークンカテゴリ | `fontFamilies` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `font-family` (`15`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `font-family` |

### 受け入れる値

この項目には独立した値の定義がありません。

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `font-family` | `resolved` | `null` |
