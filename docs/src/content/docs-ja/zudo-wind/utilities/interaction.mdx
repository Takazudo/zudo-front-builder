ネイティブコントロールの周辺にあるブラウザー動作を調整します。アクセント色、ポインターの対象、カーソル表示、サイズ変更、テキスト選択を指定できます。意味のある HTML やラベルの代わりにはなりません。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `accent-brand` | `accent-color: var(--zw-color-brand);` |
| `cursor-pointer` | `cursor: pointer;` |
| `pointer-events-none` | `pointer-events: none;` |
| `resize-y` | `resize: vertical;` |
| `select-all` | `user-select: all;` |
| `appearance-auto` | `appearance: auto;` |
| `appearance-none` | `appearance: none;` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。設定例ではチェックボックスのアクセント用に tokens.colors.brand を定義します。チェックボックス、ボタン、検索入力欄、コード文字列、テキストエリアは、標準のキーボード操作とポインター操作を保ちます。

</Details>

## 任意値と名前付きの値

アクセント色には accent-brand のような色トークン、固定値 transparent と current、または有効な任意色を指定できます。cursor、pointer-events、resize、select はカタログにある有限のキーワードを使い、テーマ値は継承しません。装飾用の検索アイコンに pointer-events-none を指定すると、クリックは下の入力欄に届きます。利用できないボタンでは not-allowed カーソルだけでなく、disabled も指定します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

<Details title={"カタログの詳細"}>

## accent

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.accent` |
| クラスパターン | `accent-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","arbitrary"],"arbitraryProperty":"accent-color","allowsFractionSlash":false,"allowsColorOpacity":true}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `colors` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `interaction` (`40`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `accent-color` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"transparent"` | `"transparent"` |
| `keyword` | `"current"` | `"currentColor"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `accent-color` | `resolved` | `null` |
