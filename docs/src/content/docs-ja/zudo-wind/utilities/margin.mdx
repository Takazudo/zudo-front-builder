margin は要素の境界線の外側に余白を作ります。通常のレイアウトで要素の周囲の空間を変えます。padding は境界線の内側に余白を作り、gap は親のレイアウトコンテナが項目間に空間を作ります。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `m-4` | `margin-top: 1rem; margin-right: 1rem; margin-bottom: 1rem; margin-left: 1rem;` |
| `mx-8` | `margin-left: 2rem; margin-right: 2rem;` |
| `my-2` | `margin-top: 0.5rem; margin-bottom: 0.5rem;` |
| `mt-2` | `margin-top: 0.5rem;` |
| `mr-4` | `margin-right: 1rem;` |
| `mb-6` | `margin-bottom: 1.5rem;` |
| `ml-8` | `margin-left: 2rem;` |

<Details title={"例の設定"}>

この例では spacingUnit: "0.25rem"、reset: "none"、strict モード、空のブレークポイントを明示しています。数値の接尾辞に単位を掛けるため、m-4 は物理的な四辺に 1rem を出力します。Tailwind のスケールやテーマは継承しません。wind-demo クラスは枠とカードの表示だけを担当し、自作 CSS は各プレビューから確認できます。

</Details>

## 任意値と名前付きの値

m-0 は margin をなくし、m-px はトークンなしで 1px を指定します。それ以外の数値には tokens.spacingUnit が必要です。m-section のような名前付きの値は tokens.spacing、mt-[18px] のような任意値はスケール不要です。margin の軸と辺は物理的な方向を使います。mx は左右、my は上下、mt/mr/mb/ml は各辺を指し、書字方向には追従しません。margin は負の値を使え、-mt-3 のように root の前にハイフンを付けます。padding と gap では負の値を使えません。auto も使えます。mx-auto は幅を指定したブロックの左右に空間があれば中央に配置し、上下の auto はレイアウトの文脈が余剰空間を配分するときに働きます。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## m

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.m` |
| クラスパターン | `m-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","scale","arbitrary"],"arbitraryProperty":"margin-top","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `3` |
| トークンカテゴリ | `spacing` |
| 負の値の規則 | `allowed` |
| 競合グループと順位 | `margin` (`10`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `margin-top`, `margin-right`, `margin-bottom`, `margin-left` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"0"` | `"0"` |
| `keyword` | `"px"` | `"1px"` |
| `keyword` | `"auto"` | `"auto"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
