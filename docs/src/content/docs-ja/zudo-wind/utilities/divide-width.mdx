後続する表示中の直下の子要素に solid ボーダーを付け、グループ内を区切ります。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `divide-x-3` | `border-left-width: 3px; border-left-style: solid;` |
| `divide-y-2` | `border-top-width: 2px; border-top-style: solid;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

divide-y は後続する表示中の兄弟に上ボーダー、divide-x は左ボーダーを付けます。どちらも物理辺を使い、引数なしでは 1px、整数ではピクセル幅、角括弧では検証済み長さを指定できます。対象辺のスタイルは solid になります。最初の表示中の子には線を付けません。hidden 属性のある要素は表示中の子の間にあっても除外されます。hidden がなく display:none だけの要素はセレクターに残ります。reverse フラグはありません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## divide-x

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.divide.width.x` |
| クラスパターン | `divide-x` or `divide-x-<suffix>` |
| 文法 | `{"acceptedKinds":["exact","integer","arbitrary"],"arbitraryProperty":"border-left-width","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `1` |
| トークンカテゴリ | トークンカテゴリなし |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `divide-width` (`28`) |
| 並び順の順位 | `0` |
| セレクタの形 | `laterVisibleSiblings` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `border-left-width`, `border-left-style` |
