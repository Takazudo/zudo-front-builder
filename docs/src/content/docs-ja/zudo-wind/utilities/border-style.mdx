対応するボーダー線のスタイル、線の非表示、またはテーブルの border-collapse を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `border-dashed` | `border-style: dashed;` |
| `border-dotted` | `border-style: dotted;` |
| `border-double` | `border-style: double;` |
| `border-none` | `border-style: none;` |
| `border-solid` | `border-style: solid;` |
| `border-collapse` | `border-collapse: collapse;` |
| `border-collapse-separate` | `border-collapse: separate;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

border-solid、border-dashed、border-dotted、border-double、border-none は border-style を設定します。線を見せるには幅ユーティリティも組み合わせます。スタイルだけでは幅を追加しません。border-none はスタイルだけを none にします。border-collapse と border-collapse-separate はテーブルの border-collapse プロパティを設定します。セルの線を接続するか分離するかを選べます。border の幅ユーティリティ自体も solid スタイルを設定します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
