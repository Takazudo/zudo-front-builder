SVG の塗りを正確なユーティリティクラスで設定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `fill-none` | `fill: none;` |
| `stroke-current` | `stroke: currentColor;` |
| `fill-current` | `fill: currentColor;` |
| `stroke-none` | `stroke: none;` |

<Details title={"例の設定"}>

これらのクラスにトークン設定は不要です。プレビューの自作 CSS は例とともに表示されます。

</Details>

## 任意値と名前付きの値

current と none の正確な形式だけが対象です。それ以外の SVG の塗りは CSS に記述してください。
