大きすぎる内容を切り取るか、見せるか、スクロール可能にするかを選びます。各軸で別の扱いにする場合は x/y 形を使います。overscroll は、内側のスクロールが端に達したとき親へジェスチャーを伝えるかを決めます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `overflow-auto` | `overflow: auto;` |
| `overflow-hidden` | `overflow: hidden;` |
| `overflow-clip` | `overflow: clip;` |
| `overflow-visible` | `overflow: visible;` |
| `overflow-scroll` | `overflow: scroll;` |
| `overflow-x-auto` | `overflow-x: auto;` |
| `overflow-x-scroll` | `overflow-x: scroll;` |
| `overflow-y-scroll` | `overflow-y: scroll;` |
| `overflow-y-auto` | `overflow-y: auto;` |
| `overscroll-auto` | `overscroll-behavior: auto;` |
| `overscroll-none` | `overscroll-behavior: none;` |
| `overscroll-contain` | `overscroll-behavior: contain;` |
| `overscroll-x-contain` | `overscroll-behavior-x: contain;` |
| `overscroll-y-contain` | `overscroll-behavior-y: contain;` |
| `overscroll-y-none` | `overscroll-behavior-y: none;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

overflow は auto、hidden、clip、visible、scroll を受け取り、x/y 形も同じ値に対応します。auto は必要なときだけスクロールを追加し、scroll は内容が収まってもスクロール領域を作ります。overscroll は両軸または片軸に auto、contain、none を指定します。いずれも固定キーワードで、トークンや任意値はありません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
