四辺すべて、軸、または一辺の物理ボーダー幅を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `border` | `border-top-width: 1px; border-top-style: solid; border-right-width: 1px; border-right-style: solid; border-bottom-width: 1px; border-bottom-style: solid; border-left-width: 1px; border-left-style: solid;` |
| `border-x-4` | `border-left-width: 4px; border-left-style: solid; border-right-width: 4px; border-right-style: solid;` |
| `border-y-2` | `border-top-width: 2px; border-top-style: solid; border-bottom-width: 2px; border-bottom-style: solid;` |
| `border-b-[3px]` | `border-bottom-width: 3px; border-bottom-style: solid;` |
| `border-l-4` | `border-left-width: 4px; border-left-style: solid;` |
| `border-r-2` | `border-right-width: 2px; border-right-style: solid;` |
| `border-t-4` | `border-top-width: 4px; border-top-style: solid;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

引数なしの border は四辺に 1px solid を出力します。数値の接尾辞はピクセル長です。border-x-4 は左右、border-y-2 は上下に作用します。x/y は書字方向に応じて変化する論理軸ではなく物理辺です。border-t、border-r、border-b、border-l は各辺を指定します。角括弧には検証済み CSS 長さを指定できます。spacingUnit は使わず、負数も使えません。幅ユーティリティは対象辺のスタイルも solid にします。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## border

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.border.width` |
| クラスパターン | `border` or `border-<suffix>` |
| 文法 | `{"acceptedKinds":["exact","integer","arbitrary"],"arbitraryProperty":"border-top-width","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `1` |
| トークンカテゴリ | トークンカテゴリなし |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `border-width` (`24`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `border-top-width`, `border-top-style`, `border-right-width`, `border-right-style`, `border-bottom-width`, `border-bottom-style`, `border-left-width`, `border-left-style` |
