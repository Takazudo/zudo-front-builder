grid-template で列と行を定義し、子要素は複数トラックをまたがせたり、開始線と終了線を指定して配置したりします。両方の軸を扱うレイアウトには grid が向いています。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `grid-cols-3` | `grid-template-columns: repeat(3,minmax(0,1fr));` |
| `grid-rows-2` | `grid-template-rows: repeat(2,minmax(0,1fr));` |
| `col-span-2` | `grid-column: span 2 / span 2;` |
| `col-start-2` | `grid-column-start: 2;` |
| `col-end-4` | `grid-column-end: 4;` |
| `row-span-2` | `grid-row: span 2 / span 2;` |
| `row-start-2` | `grid-row-start: 2;` |
| `row-end-4` | `grid-row-end: 4;` |
| `grid-cols-[7rem_1fr]` | `grid-template-columns: 7rem 1fr;` |
| `grid-rows-[auto_1fr]` | `grid-template-rows: auto 1fr;` |
| `col-start-auto` | `grid-column-start: auto;` |
| `row-end-auto` | `grid-row-end: auto;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

grid-cols-N と grid-rows-N は 1〜12 の整数を受け取り、none と subgrid も使えます。col-span-N と row-span-N は 1〜12、start/end の線番号は 1〜13 と auto に対応します。span-full は 1 / -1 です。テンプレートには CSS の任意トラックリストも指定でき、grid-cols-[7rem_1fr] のように空白をアンダースコアで表します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
