設定済みの box-shadow、任意の CSS box-shadow、または影なしを指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `shadow-panel` | `box-shadow: var(--zw-shadow-panel);` |
| `shadow-[0_12px_24px_#16324f33]` | `box-shadow: 0 12px 24px #16324f33;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

shadow-panel のような名前は tokens.shadows に設定した値だけを参照します。shadow-none は影なしのキーワードです。角括弧の値は CSS box-shadow として検証され、クラス内のアンダースコアは空白を表します。既定の影スケールも影用の不透明度修飾子もありません。カタログには ring ユーティリティもありません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
