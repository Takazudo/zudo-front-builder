アウトラインの太さ、距離、線種とは独立して色を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `outline-focus/90` | `outline-color: color-mix(in oklab, var(--zw-color-focus) 90%, transparent);` |
| `outline-[#8b1e3f]` | `outline-color: #8b1e3f;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

名前付きの色は tokens.colors を使います。outline-current と outline-transparent もキーワードとして使えます。outline-[#8b1e3f] のような任意値は CSS 色として検証されます。スラッシュ修飾子には 0〜100 の整数を指定し、色を Oklab で transparent と混ぜます。outline の根は共有されており、整数の接尾辞は幅、設定済みの色名や CSS 色は色として解決します。自動パレットはありません。
