padding は内容と境界線の間に余白を作ります。全方向、物理的な軸、または個別の辺を指定できます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `p-4` | `padding-top: 1rem; padding-right: 1rem; padding-bottom: 1rem; padding-left: 1rem;` |
| `px-8` | `padding-left: 2rem; padding-right: 2rem;` |
| `py-2` | `padding-top: 0.5rem; padding-bottom: 0.5rem;` |
| `pt-2` | `padding-top: 0.5rem;` |
| `pr-4` | `padding-right: 1rem;` |
| `pb-6` | `padding-bottom: 1.5rem;` |
| `pl-8` | `padding-left: 2rem;` |

<Details title={"例の設定"}>

この例では spacingUnit: "0.25rem"、reset: "none"、strict モード、空のブレークポイントを明示しています。p-4 は各辺に 1rem、px-8 は左右に 2rem を出力します。Tailwind のスケールやテーマは継承しません。色付きの余白と破線の内容ガイドは wind-demo の自作 CSS で、各プレビューから確認できます。

</Details>

## 任意値と名前付きの値

p-0 は余白をなくし、p-px はトークンなしで 1px を指定します。それ以外の数値には tokens.spacingUnit が必要です。p-card のような名前付きの値は tokens.spacing で設定します。p-[18px] などの任意値はスケール不要です。同じ値の形式を各軸と各辺で使えます。padding は論理的な始端・終端ではなく物理的な辺に作用し、負の値や auto は使えません。任意値の calc 内の空白はアンダースコアで表します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.p` |
| クラスパターン | `p-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","scale","arbitrary"],"arbitraryProperty":"padding-top","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `spacing` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `padding` (`9`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `padding-top`, `padding-right`, `padding-bottom`, `padding-left` |
