後続する表示中の直下の子要素に、区切り線の色を設定します。線幅は divide-width と組み合わせます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `divide-accent/75` | `border-top-color: color-mix(in oklab, var(--zw-color-accent) 75%, transparent); border-right-color: color-mix(in oklab, var(--zw-color-accent) 75%, transparent); border-bottom-color: color-mix(in oklab, var(--zw-color-accent) 75%, transparent); border-left-color: color-mix(in oklab, var(--zw-color-accent) 75%, transparent);` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

名前は tokens.colors に設定した値だけを参照します。divide-current、divide-transparent と検証済みの角括弧色も使えます。スラッシュには 0〜100 の整数を指定し、色を Oklab で transparent と混ぜます。divide の色ルールは、該当する後続の子要素に四辺すべての border-color を設定します。線の幅と方向には divide-x または divide-y を組み合わせます。hidden 属性の子要素は除外されるため、次の表示中の子は直前の表示中の子との間で区切られます。コンテナ自身の色を変えるユーティリティではありません。

## divide

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.divide.color` |
| クラスパターン | `divide-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","arbitrary"],"arbitraryProperty":"border-top-color","allowsFractionSlash":false,"allowsColorOpacity":true}` |
