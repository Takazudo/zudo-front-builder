display で、文章の流れに入るか、ブロックとして改行するか、子要素を flex または grid で並べるかを選びます。インラインのまま幅も指定したい場合は inline-block、レイアウトから箱ごと取り除く場合は hidden を使います。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `inline` | `display: inline;` |
| `inline-block` | `display: inline-block;` |
| `block` | `display: block;` |
| `flex` | `display: flex;` |
| `inline-flex` | `display: inline-flex;` |
| `grid` | `display: grid;` |
| `inline-grid` | `display: inline-grid;` |
| `hidden` | `display: none;` |
| `contents` | `display: contents;` |
| `flow-root` | `display: flow-root;` |
| `list-item` | `display: list-item;` |
| `table` | `display: table;` |
| `table-caption` | `display: table-caption;` |
| `table-cell` | `display: table-cell;` |
| `table-column` | `display: table-column;` |
| `table-column-group` | `display: table-column-group;` |
| `table-footer-group` | `display: table-footer-group;` |
| `table-header-group` | `display: table-header-group;` |
| `table-row` | `display: table-row;` |
| `table-row-group` | `display: table-row-group;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

このファミリーは値の接尾辞や任意値を持たない、8 個の固定クラスです。inline、block、inline-block、flex、inline-flex、grid、inline-grid、hidden は display の種類に対応します。hidden は display:none です。invisible は箱の場所を残す別の visibility ユーティリティです。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
