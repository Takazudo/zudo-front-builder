キャプション、本文、見出しなど用途に合わせて文字サイズを指定します。名前付きの font-size トークンにはサイズと行の高さを組み合わせられ、任意値では検証済みの CSS 値を1要素に指定できます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `text-copy` | `font-size: var(--zw-font-size-copy); line-height: var(--zw-font-size-copy-leading);` |
| `text-[20px]` | `font-size: 20px;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。各例は size と lineHeight を持つ tokens.fontSizes を宣言します。lineHeight がある名前付きテキストトークンは両方のプロパティを出力し、text-[20px] は font-size だけを出力します。wind-demo は枠と余白のみを加えます。

</Details>

## 任意値と名前付きの値

設定済みの値には text-copy、1回だけの指定には text-[20px] を使います。名前付き font-size は text ルートを色トークンと共有するため、同じ設定内で名前が重複しないようにします。ペアの leading は font-size トークンの一部です。slash 構文を付けない任意サイズから行の高さは自動で作られません。文章に決まったリズムが必要な場合は行の高さも明示します。

## text

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.text.size` |
| クラスパターン | `text-<suffix>` |
| 文法 | `{"acceptedKinds":["token","arbitrary"],"arbitraryProperty":"font-size","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | この項目には独立した値の定義がありません。 |
| トークンカテゴリ | `fontSizes` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `font-size` (`17`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `font-size`, `line-height` |

### 受け入れる値

この項目には独立した値の定義がありません。

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `font-size` | `resolved` | `null` |
| `line-height` | `optionalFontSizeLeading` | `null` |
