既存の下線を文字から離したり近づけたりします。オフセットは下線の位置を変えますが、下線の有無は切り替えません。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `underline-offset-4` | `text-underline-offset: 4px;` |
| `underline-offset-[0.15em]` | `text-underline-offset: 0.15em;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。ブラウザー標準のリンク下線を使い、text-underline-offset の違いが分かるようにしています。wind-demo はコンテナとリンク色のみを整えます。

</Details>

## 任意値と名前付きの値

underline-offset-4 のような整数の接尾辞は 4px です。underline-offset-[0.15em] のような任意値では、文字サイズに合わせて変化する長さを指定できます。このファミリーには名前付きオフセット、割合、負の値、auto キーワードはありません。下線と文字の関係が分かる範囲で間隔を調整します。
