要素を時計回りまたは反時計回りに回転します。CSS の rotate プロパティを使うため、x と y の translate ユーティリティと独立して合成できます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `rotate-12` | `rotate: 12deg;` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。一つ目の図では translate-x-8、translate-y-4、rotate-12 を同時に適用し、もう一つでは負の度数と任意の回転角を比べます。図の CSS は四角形を描いて配置するためだけに使います。

</Details>

## 任意値と名前付きの値

0 から 360 までの整数は度として解釈します。対応する整数にマイナスを付けると反時計回りになります。任意の CSS 角度では deg、rad、grad、turn を使えます。例: rotate-[0.125turn]。名前付き回転スケールはありません。v1 のカタログには transform、scale、skew、GPU 用 transform ユーティリティは含まれません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
