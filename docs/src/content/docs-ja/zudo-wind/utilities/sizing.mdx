width、height、size で寸法を直接設定し、min/max の制約で可変範囲を決めます。w-full と max-w-* を組み合わせると、幅が親に追従しながら読みやすい最大幅で止まる内容領域を作れます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `size-12` | `width: 3rem; height: 3rem;` |
| `h-24` | `height: 6rem;` |
| `w-1/2` | `width: calc(100% * 1 / 2);` |
| `max-w-64` | `max-width: 16rem;` |
| `min-w-0` | `min-width: 0;` |
| `min-h-24` | `min-height: 6rem;` |
| `max-h-32` | `max-height: 8rem;` |
| `size-card` | `width: var(--zw-size-card); height: var(--zw-size-card);` |
| `max-w-reading` | `max-width: var(--zw-size-reading);` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

spacingUnit は 0.25rem に設定しているため、w-16 は 4rem です。w-1/2 のような分数、full/min/max/fit/auto/screen/dvh などの組み込み値、tokens.sizes や tokens.spacing の名前付き値、w-[18rem] のような任意 CSS 値も使えます。size は幅と高さを同時に設定します。このプレビューでは tokens.sizes.card と tokens.sizes.reading を明示します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
