visibility で場所を保ったまま要素を隠したり、再び表示したりします。箱をレイアウトから取り除き、後続の内容を詰めたい場合は display ファミリーの hidden を使います。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `invisible` | `visibility: hidden;` |
| `visible` | `visibility: visible;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

このファミリーは任意値のない2つの固定クラスです。visible は visibility:visible、invisible は visibility:hidden を設定します。箱はレイアウト上の場所を保ちますが、visibility:hidden の内容は通常アクセシビリティツリーから外れ、操作できません。hidden は別の display:none ユーティリティです。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
