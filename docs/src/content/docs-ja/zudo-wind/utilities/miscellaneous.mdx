行内の垂直位置、ボックスの寸法、置換要素の収まり方、そして支援技術に伝えたまま視覚的に隠す補足テキストを調整します。

| --- | --- |

| `align-top` | `vertical-align: top;` |

| `box-content` | `box-sizing: content-box;` |

| `object-fill` | `object-fit: fill;` |
| `object-none` | `object-fit: none;` |
| `object-scale-down` | `object-fit: scale-down;` |

| `sr-only` | `position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0,0,0,0); white-space: nowrap; border-width: 0;` |
| `not-sr-only` | `position: static; width: auto; height: auto; padding: 0; margin: 0; overflow: visible; clip: auto; clip-path: none; white-space: normal;` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。データ画像は intrinsic size が 160 × 100 のインライン SVG なので、object-fit の結果を再現できます。自作 CSS は比較用の枠とボックス寸法を設定し、配置、サイズ計算、画像の収まり方、sr-only の宣言は zudo-wind が出力します。

## 任意値と名前付きの値

このファミリーの項目はすべて固定キーワードで、名前付きトークンスケールや任意値形式はありません。vertical-align は行内コンテンツを行に対して配置し、flex や grid の整列には使いません。box-border は padding と border を幅に含め、box-content は内容領域の幅を指定します。object-fit は置換要素の内容を要素の枠にどう収めるかを決めます。sr-only は支援技術のツリーには残したまま視覚的に切り取ります。視覚で読む人に必要な情報を隠す用途には使わないでください。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
