ボーダー全体、軸、または物理的な一辺に色を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `border-ink` | `border-top-color: var(--zw-color-ink); border-right-color: var(--zw-color-ink); border-bottom-color: var(--zw-color-ink); border-left-color: var(--zw-color-ink);` |
| `border-x-accent/85` | `border-left-color: color-mix(in oklab, var(--zw-color-accent) 85%, transparent); border-right-color: color-mix(in oklab, var(--zw-color-accent) 85%, transparent);` |
| `border-y-focus` | `border-top-color: var(--zw-color-focus); border-bottom-color: var(--zw-color-focus);` |
| `border-b-alert/90` | `border-bottom-color: color-mix(in oklab, var(--zw-color-alert) 90%, transparent);` |
| `border-l-ink` | `border-left-color: var(--zw-color-ink);` |
| `border-r-accent` | `border-right-color: var(--zw-color-accent);` |
| `border-t-focus` | `border-top-color: var(--zw-color-focus);` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

border-ink のような名前は tokens.colors に設定します。既定パレットはありません。border-current と border-transparent も使えます。border-x-accent/85 のような色のスラッシュ修飾子には 0〜100 の整数を指定します。角括弧には検証済み CSS 色を指定できます。border、border-x、border-y と辺別の形は物理辺を選びます。色を見せるには幅ユーティリティと組み合わせます。幅と色は同じクラス根を共有するため、数値の接尾辞は幅、設定済み色名は色として解釈されます。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## border

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.border.color` |
| クラスパターン | `border-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","arbitrary"],"arbitraryProperty":"border-top-color","allowsFractionSlash":false,"allowsColorOpacity":true}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `colors` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `border-color` (`25`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `border-top-color`, `border-right-color`, `border-bottom-color`, `border-left-color` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"transparent"` | `"transparent"` |
| `keyword` | `"current"` | `"currentColor"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `border-top-color` | `resolved` | `null` |
| `border-right-color` | `resolved` | `null` |
| `border-bottom-color` | `resolved` | `null` |
| `border-left-color` | `resolved` | `null` |

### カタログの例

| クラスの例 | 期待される宣言 |
