色トークン、キーワード、任意の色からテキスト装飾の色を設定します。不透明度も指定できます。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## decoration

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.decoration.color` |
| クラスパターン | `decoration-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","arbitrary"],"arbitraryProperty":"text-decoration-color","allowsFractionSlash":false,"allowsColorOpacity":true}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `colors` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `text-decoration-color` (`45`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `text-decoration-color` |
