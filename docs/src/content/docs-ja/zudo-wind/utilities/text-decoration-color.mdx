見える下線、上線などのある要素で、text-decoration の色、太さ、線種を設定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `decoration-accent` | `text-decoration-color: var(--zw-color-accent);` |
| `decoration-2` | `text-decoration-thickness: 2px;` |
| `decoration-solid` | `text-decoration-style: solid;` |
| `decoration-double` | `text-decoration-style: double;` |
| `decoration-dotted` | `text-decoration-style: dotted;` |
| `decoration-dashed` | `text-decoration-style: dashed;` |
| `decoration-wavy` | `text-decoration-style: wavy;` |
| `decoration-[#b42318]/80` | `text-decoration-color: color-mix(in oklab, #b42318 80%, transparent);` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。名前付きの例では tokens.colors.accent を設定します。自作 CSS は読みやすい文字色を指定してブラウザー標準のリンク下線を残し、text-decoration-color は指定しません。

</Details>

## 任意値と名前付きの値

decoration-accent は tokens.colors.accent を参照します。decoration-current は要素の現在の文字色を使い、decoration-transparent は装飾の位置を保ったまま色を透明にします。decoration-[#b42318] のような任意色は CSS カラーパーサーで検証され、/80 のような対応する不透明度修飾子は色に透明度を加えます。このファミリーに自動パレットはないため、名前付き色はすべて設定が必要です。 整数の decoration-2 は text-decoration-thickness: 2px を出力し、0 以上の角括弧付き長さも使えます。正確な decoration-solid、-double、-dotted、-dashed、-wavy は text-decoration-style を設定します。完全な色トークンが設定されていれば style 名より優先されます。thickness/style の負数とスラッシュは拒否され、decoration-auto と decoration-from-font は未対応です。
