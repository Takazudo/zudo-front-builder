リストマーカーの種類と、リスト項目のテキスト枠に対する位置を選びます。ul や ol の意味構造は HTML で用意します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `list-disc` | `list-style-type: disc;` |
| `list-decimal` | `list-style-type: decimal;` |
| `list-none` | `list-style-type: none;` |
| `list-inside` | `list-style-position: inside;` |
| `list-outside` | `list-style-position: outside;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。自作 CSS はデモカードを配置するだけで、list-style-type と list-style-position はユーティリティに任せます。リストの意味構造は HTML のリスト要素で表します。

</Details>

## 任意値と名前付きの値

list-disc、list-decimal、list-none はマーカーの種類を指定します。list-inside と list-outside は独立して位置を指定するため、種類と位置は必要に応じて組み合わせられます。マーカーを消したナビゲーションでもリンクテキストとナビゲーションの意味づけは必要です。現在のカタログには固定の選択肢があり、名前付きトークンや任意マーカー構文はありません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
