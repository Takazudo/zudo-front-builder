開始値から終了値へ変わるときの加速と減速を決め、トランジションの進み方を選びます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `ease-gentle` | `transition-timing-function: var(--zw-ease-gentle);` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。名前付きの例では tokens.easings.gentle に cubic-bezier(0.2, 0, 0, 1) を設定し、もう一つの例では CSS のタイミング関数を直接使います。どちらも 300ms で 8px だけ動き、hover と focus-visible で操作できます。prefers-reduced-motion の利用者には自作デモ CSS が時間を 0 にします。

</Details>

## 任意値と名前付きの値

組み込みの名前付きイージング値はありません。tokens.easings に値を設定し、ease-gentle のように ease-&lt;name&gt; で参照します。ease-[steps(3,end)] のような任意形式には、CSS のタイミング関数を一つ指定できます。wind.defaultTransitionTimingFunction にはトークン名ではなく CSS のキーワードまたは関数を指定します。同じバリアント区画では、明示した ease-* がこの初期値を上書きします。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

<Details title={"カタログの詳細"}>

## ease

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.ease` |
| クラスパターン | `ease-<suffix>` |
| 文法 | `{"acceptedKinds":["token","arbitrary"],"arbitraryProperty":"transition-timing-function","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | この項目には独立した値の定義がありません。 |
| トークンカテゴリ | `easings` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `easing` (`37`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `transition-timing-function` |

### 受け入れる値

この項目には独立した値の定義がありません。

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `transition-timing-function` | `resolved` | `null` |

### カタログの例

| クラスの例 | 期待される宣言 |
| --- | --- |
| `ease-[ease-in]` | `transition-timing-function: ease-in` |
