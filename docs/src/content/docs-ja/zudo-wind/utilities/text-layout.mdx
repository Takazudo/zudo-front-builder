文字揃え、空白や改行の扱い、長い単語や1行テキストの収め方を調整します。まず通常の折り返しを使い、内容と幅に合わせて必要な挙動を選びます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `text-center` | `text-align: center;` |
| `whitespace-pre-wrap` | `white-space: pre-wrap;` |
| `break-all` | `word-break: break-all;` |
| `break-normal` | `overflow-wrap: normal; word-break: normal;` |
| `break-words` | `overflow-wrap: break-word;` |
| `wrap-anywhere` | `overflow-wrap: anywhere;` |
| `truncate` | `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。折り返しを確認しやすい固定幅は wind-demo CSS で指定します。この CSS は text-align、white-space、word-break、overflow-wrap、truncate を設定しません。日本語はブラウザーが許可する自然な文字境界で折り返します。

</Details>

## 任意値と名前付きの値

text-left、text-center、text-right、text-justify、text-start、text-end は文字揃えを制御します。start と end は要素の方向に従います。whitespace-* は空白やソース内の改行を畳むか保持するか、折り返すかを選びます。break-all は任意の文字間で分割し、break-words は長い単語の緊急折り返しを許可し、wrap-anywhere は min-content の幅にも影響します。break-normal は通常の word-break と overflow-wrap に戻します。truncate は overflow hidden、ellipsis、nowrap をまとめて指定するため、切り詰めるには実際の幅制限が必要です。日本語は通常の行分割でも文字単位で折り返せるため、長い英数字の識別子と日本語の文章を合わせて確認してください。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
