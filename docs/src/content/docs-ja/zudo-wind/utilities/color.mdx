文字の前景色を指定します。背景色や周囲のレイアウトには作用しません。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `text-ink` | `color: var(--zw-color-ink);` |
| `text-[#8b1e3f]/90` | `color: color-mix(in oklab, #8b1e3f 90%, transparent);` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

text-ink のような名前は tokens.colors に設定した値だけを参照します。text-current と text-transparent もキーワードとして使えます。text-[#8b1e3f] のような角括弧の値は CSS 色として検証されます。スラッシュ修飾子には 0〜100 の整数を指定でき、色を Oklab で transparent と混ぜます。text-accent/85 は文字色自体を薄くします。このファミリーに組み込みパレットはありません。

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.text.color` |
