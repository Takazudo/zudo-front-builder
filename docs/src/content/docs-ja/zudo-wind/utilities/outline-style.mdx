対応するアウトラインの線種を選びます。アウトラインを消す指定もあります。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `outline-dashed` | `outline-style: dashed;` |
| `outline-dotted` | `outline-style: dotted;` |
| `outline-double` | `outline-style: double;` |
| `outline-none` | `outline-style: none;` |
| `outline-solid` | `outline-style: solid;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

outline-solid、outline-dashed、outline-dotted、outline-double、outline-none は完全一致のクラスで outline-style を設定します。幅と色は含まれないため、見える線には幅と色のユーティリティも組み合わせます。outline-none はアウトラインを完全に削除します。使う場合は、明確な別のフォーカス表示を用意してください。カタログには Tailwind の outline-hidden は含まれません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
