文字色とは独立して、要素の背景色を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `bg-panel` | `background-color: var(--zw-color-panel);` |
| `bg-accent/18` | `background-color: color-mix(in oklab, var(--zw-color-accent) 18%, transparent);` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

bg-panel のような名前は tokens.colors に設定します。bg-current と bg-transparent もキーワードとして使えます。bg-[#e7f0f5] のように角括弧で CSS 色を指定できます。色のスラッシュ修飾子には 0〜100 の整数を使い、背景色だけを transparent と混ぜます。要素内の文字全体が薄くなるわけではありません。Tailwind のパレットは仮定しません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## bg

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.background` |
| クラスパターン | `bg-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","arbitrary"],"arbitraryProperty":"background-color","allowsFractionSlash":false,"allowsColorOpacity":true}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `colors` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `background` (`23`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `background-color` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"transparent"` | `"transparent"` |
| `keyword` | `"current"` | `"currentColor"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `background-color` | `resolved` | `null` |
