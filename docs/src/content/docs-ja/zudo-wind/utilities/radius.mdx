四隅、物理辺の二つの角、または一つの角を丸めます。

## クラスと CSS の早見表

## 任意値と名前付きの値

名前付きの値は tokens.radii を参照します。rounded-card は 0.75rem、rounded-pill は 9999px と設定しています。rounded-none と rounded-full は組み込みキーワードで、それぞれ 0 と 9999px になります。rounded-[18px] のような角括弧には検証済み CSS 長さを指定できます。辺の名前は物理方向で、t/r/b/l は上/右/下/左、二文字の形は一つの角を選びます。負数は使えません。既定の半径スケールは継承しません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## rounded

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.rounded` |
| クラスパターン | `rounded-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","arbitrary"],"arbitraryProperty":"border-top-left-radius","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `2` |
| トークンカテゴリ | `radii` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `radius` (`27`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `border-top-left-radius`, `border-top-right-radius`, `border-bottom-right-radius`, `border-bottom-left-radius` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"none"` | `"0"` |
| `keyword` | `"full"` | `"9999px"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `border-top-left-radius` | `resolved` | `null` |
| `border-top-right-radius` | `resolved` | `null` |

| `border-bottom-left-radius` | `resolved` | `null` |
