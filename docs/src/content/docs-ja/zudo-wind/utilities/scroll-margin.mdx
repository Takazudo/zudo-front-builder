scroll-margin は、フラグメント移動やスクロールスナップなどでブラウザーが対象を表示範囲へ移動するとき、対象の周囲に追加の範囲を設けます。要素の周囲に見えるレイアウト空間は作りません。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `scroll-m-6` | `scroll-margin-top: 1.5rem; scroll-margin-right: 1.5rem; scroll-margin-bottom: 1.5rem; scroll-margin-left: 1.5rem;` |
| `scroll-mx-8` | `scroll-margin-left: 2rem; scroll-margin-right: 2rem;` |
| `scroll-my-2` | `scroll-margin-top: 0.5rem; scroll-margin-bottom: 0.5rem;` |
| `scroll-mb-4` | `scroll-margin-bottom: 1rem;` |
| `scroll-ml-6` | `scroll-margin-left: 1.5rem;` |
| `scroll-mr-6` | `scroll-margin-right: 1.5rem;` |
| `scroll-mt-8` | `scroll-margin-top: 2rem;` |

<Details title={"例の設定"}>

この例では spacingUnit: "0.25rem"、reset: "none"、strict モード、空のブレークポイントを明示しています。各プレビューには、独自のスクロール枠の中に実際のリンクと対象があります。ネイティブな base 要素を about:srcdoc に向け、#top-target のようなフラグメントをプレビュー内の文書で解決します。数値の接尾辞には spacingUnit を掛け、Tailwind のスケールやテーマは継承しません。wind-demo クラスはスクロール枠と対象の表示だけを担当します。

</Details>

## 任意値と名前付きの値

scroll-m-0 は追加範囲をなくし、scroll-m-px はトークンなしで 1px を指定します。それ以外の数値には tokens.spacingUnit、scroll-mt-sticky のような名前付きの値には tokens.spacing が必要です。scroll-mt-[72px] のような任意の長さは spacing トークン不要です。-scroll-mt-4 のように root の前にハイフンを付けると負の値を使えます。x と y の root は物理的な辺を指します。scroll-mx は左右、scroll-my は上下です。個別の辺も論理的な start/end ではなく物理的な辺を指定します。位置を調整する対象側に scroll-margin を設定します。すべての対象に共通の内側余白を設ける場合は、スクロールコンテナ側に scroll-padding を設定します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
