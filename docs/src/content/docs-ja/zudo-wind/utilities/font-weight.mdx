フォントファミリーやサイズを変えずに、文字の線の太さを調整します。繰り返し使う役割には名前付きの重みを、設定した尺度にない値には任意の数値を使います。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `font-medium` | `font-weight: var(--zw-font-weight-medium);` |
| `font-[550]` | `font-weight: 550;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。各例は tokens.fontWeights に regular 400、medium 500、strong 700 を設定します。wind-demo クラスはラベルと枠だけを整え、font-weight は指定しません。

</Details>

## 任意値と名前付きの値

font-medium は tokens.fontWeights.medium を参照します。font-[550] のようなクラスは検証済みの任意の font-weight 値を指定します。見た目に反映できる重みは選択したフォントに依存します。ブラウザーによる擬似的な太字化や可変フォントの軸によっても印象が変わります。

## font

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.font.weight` |
| クラスパターン | `font-<suffix>` |
| 文法 | `{"acceptedKinds":["token","arbitrary"],"arbitraryProperty":"font-weight","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | この項目には独立した値の定義がありません。 |
| トークンカテゴリ | `fontWeights` |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `font-weight` (`16`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `font-weight` |

### 受け入れる値

この項目には独立した値の定義がありません。
