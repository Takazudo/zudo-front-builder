ソースの単語を変えずに、文字装飾、英字の大文字小文字、フォントの表示方法を調整します。異なる CSS プロパティを扱うため、必要な挙動だけを組み合わせます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `underline` | `text-decoration-line: underline;` |
| `overline` | `text-decoration-line: overline;` |
| `line-through` | `text-decoration-line: line-through;` |
| `no-underline` | `text-decoration-line: none;` |
| `uppercase` | `text-transform: uppercase;` |
| `lowercase` | `text-transform: lowercase;` |
| `capitalize` | `text-transform: capitalize;` |
| `normal-case` | `text-transform: none;` |
| `italic` | `font-style: italic;` |
| `not-italic` | `font-style: normal;` |
| `tabular-nums` | `font-variant-numeric: tabular-nums;` |
| `antialiased` | `-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。各クラスは挙動を確認するテキストに直接付けます。デモ用 CSS はレイアウト、枠、余白、リンク色のみを加えます。大文字小文字の変換はラテン文字に作用し、かなや漢字は変換しません。

</Details>

## 任意値と名前付きの値

underline、overline、line-through、no-underline は text-decoration-line を指定します。4つの case クラスは text-transform を扱い、normal-case は none に戻します。italic と not-italic は font-style を指定します。tabular-nums は等幅の数字を要求しますが、選んだフォントが対応している場合にだけ見た目に表れます。antialiased は環境依存のフォントスムージングを設定するため、ブラウザーや OS によって差が小さいことがあります。このファミリーは固定クラスで、名前付き値トークンはありません。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
