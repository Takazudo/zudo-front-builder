幅が変わってもメディア枠、サムネイル、埋め込み表示の形を保つには aspect-ratio を使います。一方の寸法が auto の場合、比率からもう一方が決まります。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `aspect-video` | `aspect-ratio: 16 / 9;` |
| `aspect-square` | `aspect-ratio: 1 / 1;` |
| `aspect-3/2` | `aspect-ratio: 3 / 2;` |
| `aspect-auto` | `aspect-ratio: auto;` |
| `aspect-4/3` | `aspect-ratio: 4 / 3;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

名前付き値は auto、square（1:1）、video（16:9）です。aspect-3/2 のような数値分数と、括弧内の CSS 任意値も使えます。aspect token は継承も必須設定もありません。aspect-auto は比率を自動のままにし、別の寸法指定や内容に形を任せます。
