flex または grid コンテナで、子要素の位置を調整します。items は交差軸、flex の justify は主軸、place-items は grid item の両軸を扱い、self は個別の項目を上書きします。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `items-center` | `align-items: center;` |
| `justify-between` | `justify-content: space-between;` |
| `self-end` | `align-self: flex-end;` |
| `place-items-center` | `place-items: center;` |
| `self-start` | `align-self: flex-start;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

各 root が受け取る値は固定キーワードです。items と self は start、end、center、baseline、stretch、justify は start、end、center、between、around、evenly、place-items は start、end、center、stretch に対応します。指定先には該当するレイアウトコンテキストと空間が必要です。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## items

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.items` |
| クラスパターン | `items-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword"],"arbitraryProperty":null,"allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `5` |
| トークンカテゴリ | トークンカテゴリなし |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `alignment` (`7`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `align-items` |
