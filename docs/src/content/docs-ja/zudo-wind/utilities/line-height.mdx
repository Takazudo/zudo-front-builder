テキストの行と行の間隔を調整します。短いラベルや大きな見出しには詰めた値、本文には読みやすい余裕を持たせた値が向きます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `leading-copy` | `line-height: var(--zw-leading-copy);` |
| `leading-[1.8]` | `line-height: 1.8;` |

<Details title={"例の設定"}>

共通のプレビュー設定では spec 1、reset none、strict モード、spacingUnit 0.25rem、ブレークポイントなしを明示しています。トークンを使う例は tokens.lineHeights を宣言します。名前付きの compact と copy は倍率で、leading-[1.8] は任意の倍率です。leading ユーティリティから font-size トークンは生成されません。

</Details>

## 任意値と名前付きの値

役割に合わせた倍率には leading-copy のような名前を付けられます。leading-none は tokens.lineHeights.none があればその値を使い、なければ 1 にフォールバックします。角括弧には倍率や長さなど、検証済みの line-height 値を指定できます。行の高さは継承されるため、同じリズムを共有する最小のブロックに適用します。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)

## leading

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.leading` |
| クラスパターン | `leading-<suffix>` |
| 文法 | `{"acceptedKinds":["token","arbitrary"],"arbitraryProperty":"line-height","allowsFractionSlash":false,"allowsColorOpacity":false}` |
