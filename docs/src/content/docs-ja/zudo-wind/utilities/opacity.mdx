要素全体とその子要素に opacity を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `opacity-55` | `opacity: 0.55;` |
| `opacity-[0.35]` | `opacity: 0.35;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

整数の接尾辞は 0〜100 の割合です。opacity-55 は 0.55、opacity-100 は完全不透明になります。角括弧には 0〜1 の数値、または 0%〜100% の割合を指定できます。このユーティリティは要素全体と子要素を一緒に薄くします。色のスラッシュ修飾子は異なり、色プロパティだけを transparent と混ぜます。小さな文字やコントロールではコントラストが落ちるため、要素 opacity の使用に注意してください。
