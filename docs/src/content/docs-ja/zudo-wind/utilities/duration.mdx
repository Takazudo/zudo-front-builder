トランジションにかかる時間を設定します。duration は変化させるプロパティを選ばないため、トランジション系ユーティリティと状態変化を組み合わせます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `duration-150` | `transition-duration: 150ms;` |

<Details title={"例の設定"}>

すべてのプレビューで spec: 1、reset: "none"、strict モード、spacingUnit: "0.25rem"、空のブレークポイント、defaultTransitionTimingFunction: "ease" を明示します。ボタンは hover または focus-visible で 8px だけ動き、最長の例も 420ms です。prefers-reduced-motion: reduce では自作デモ CSS が時間を 0 にします。

</Details>

## 任意値と名前付きの値

整数の接尾辞は 0 から 60000 までのミリ秒として解釈されるため、duration-300 は 300ms、duration-0 は補間なしです。duration-[420ms] なら個別の CSS 時間を指定できます。名前付きの時間スケールはありません。150ms の初期値はトランジション系ユーティリティが設定し、duration-* を追加すると上書きします。

**関連ガイド:** [ユーティリティの文法](../utility-grammar.mdx) · [バリアント](../variants.mdx)
