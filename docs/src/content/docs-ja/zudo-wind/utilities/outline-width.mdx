アウトラインの太さと要素からの距離を指定します。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `outline-2` | `outline-width: 2px; outline-style: solid;` |
| `outline-offset-4` | `outline-offset: 4px;` |

<Details title={"例の設定"}>

共通プレビュー設定では spec 1、reset: "none"、strict モード、tokens.spacingUnit: "0.25rem"、ブレークポイントなしを明示しています。名前付きの値は各例で設定し、既定のパレットやテーマは継承しません。wind-demo クラスはデモ用の自作スタイルです。各例では、その CSS とユーティリティの宣言を分けて確認できます。

</Details>

## 任意値と名前付きの値

outline-2 はピクセル幅を使い、幅とともに solid スタイルも設定します。角括弧には検証済み CSS 長さを指定できます。outline-offset-4 はアウトラインと要素の間を 4px 離します。offset は整数ピクセルまたは任意の長さを受け取り、負数も使えます。アウトラインはレイアウト上の場所を取りません。幅と offset は別のカタログ項目なので個別に調整できます。操作可能なコントロールではフォーカス表示を維持してください。

## outline

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.outline.width` |
| クラスパターン | `outline` or `outline-<suffix>` |
| 文法 | `{"acceptedKinds":["exact","integer","arbitrary"],"arbitraryProperty":"outline-width","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `1` |
| トークンカテゴリ | トークンカテゴリなし |
| 負の値の規則 | `forbidden` |
| 競合グループと順位 | `outline-width` (`30`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `outline-width`, `outline-style` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `exact` | `null` | `"1px"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `outline-width` | `resolved` | `null` |
| `outline-style` | `fixed` | `"solid"` |

### カタログの例

| クラスの例 | 期待される宣言 |
| --- | --- |
