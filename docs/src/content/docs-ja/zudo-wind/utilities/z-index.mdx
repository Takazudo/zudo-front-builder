同じ stacking context 内で重なる位置指定要素の前後関係を z-index で決めます。要素が同じ context に属する場合、大きい数値が小さい数値より手前に描画されます。

## クラスと CSS の早見表

| クラスの例 | 期待される宣言 |
| --- | --- |
| `z-10` | `z-index: 10;` |
| `z-auto` | `z-index: auto;` |
| `z-0` | `z-index: 0;` |
| `z-dialog` | `z-index: var(--zw-z-dialog);` |
| `-z-[1]` | `z-index: -1;` |

<Details title={"例の設定"}>

すべてのプレビューは spec 1、reset "none"、strict モード、spacingUnit "0.25rem"、ブレークポイントなしを明示した設定から始まります。数値の spacing はこの単位を掛けて解決し、Tailwind のテーマは継承しません。wind-demo クラスはデモ用の自作スタイルで、HTML と一緒に CSS を確認できます。

</Details>

## 任意値と名前付きの値

整数、-z-10 や -z-[1] のような負の値、auto、tokens.zIndices の名前付きトークン、z-[42] のような CSS 任意値に対応します。角括弧の外側に負の接頭辞を置きます。角括弧内に符号付き数値を置く書き方は拒否されます。このプレビューは tokens.zIndices.dialog に 30 を設定し、z-dialog という役割名で参照します。z-index は要素を移動せず、祖先の stacking context を必ずしも越えません。

## z

| フィールド | 値 |
| --- | --- |
| カタログ識別子 | `v1.z` |
| クラスパターン | `z-<suffix>` |
| 文法 | `{"acceptedKinds":["keyword","token","integer","arbitrary"],"arbitraryProperty":"z-index","allowsFractionSlash":false,"allowsColorOpacity":false}` |
| 受け入れる値 | `1` |
| トークンカテゴリ | `zIndices` |
| 負の値の規則 | `allowed` |
| 競合グループと順位 | `z-index` (`14`) |
| 並び順の順位 | `0` |
| セレクタの形 | `ownElement` |
| 仕様バージョン | `1` |
| 出力するプロパティ | `z-index` |

### 受け入れる値

| 種類 | 接尾辞 | 出力される値 |
| --- | --- | --- |
| `keyword` | `"auto"` | `"auto"` |

### 宣言テンプレート

| プロパティ | 値の種類 | 固定値 |
| --- | --- | --- |
| `z-index` | `resolved` | `null` |
