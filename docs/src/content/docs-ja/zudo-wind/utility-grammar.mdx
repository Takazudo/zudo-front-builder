## 完全な候補を記述する

スキャナーはソースをテキストとして読みます。アプリケーションを実行してクラス名を組み立てることはありません。`grid-cols-2` のように候補全体をソースに記述してください。`sm:hover:bg-panel` を使うには、`sm` と `colors.panel` の設定が必要です。`` `p-${size}` `` のような文字列からコンパイラが候補を推測することはできません。

一度だけ使う値は、対応するユーティリティの角括弧内に記述します。括弧内の空白はアンダースコアで書きます。CSS の `calc()` では二項の `+` と `-` の前後に空白が必要なので、`w-[calc(100vw_-_2rem)]` と記述します。エスケープした `\_` はアンダースコアのまま残ります。

次の無効な綴りは診断フィクスチャです。表示されるソースと期待されるコードは、コンパイラが確認する同じレコードから生成されます。

{/* wind-preview: guide-utility-grammar/calc-needs-underscores "calc の空白にはアンダースコアを使う" */}

```html
<div class="w-[calc(100vw-2rem)]">w-[calc(100vw-2rem)]</div>
```

## 候補の形

候補は完全なユーティリティで、任意でコロン区切りのバリアントを先頭に付けられます。一般形は `variant:variant:utility` です。トークナイザーは角括弧、丸括弧、引用符の対応を取ってから分割するため、その内側のコロンとスラッシュはバリアントや修飾子の開始にはなりません。文字どおりの空白、NUL、ほかの制御文字、禁止された外側の句読記号は使えません。

| 規則 | 受け入れる例 | 拒否される例と結果 |
| --- | --- | --- |
| G01 candidate | `sm:dark:hover:bg-panel`。`sm`、ダークモード、`colors.panel` の設定が必要 | `hover::block` — 空の区間、ZW001 |
| G02 variant | `focus-visible:block` | `md` が未設定の場合の `md:block`、ZW002 |
| G03 breakpoint | `sm` が設定済みの場合の `max-sm:hidden` | `md` がない場合の `max-md:hidden`、ZW002 |
| G04 dark | ダークモードが設定済みの場合の `dark:block` | ダークモードが無効な場合の `dark:block`、ZW002 |
| G05 state | `first:pt-0` | `hover:focus:hover:block` — 状態の重複、ZW003 |
| G06 relation | `group-open:rotate-90` | `group-hover/menu:block` — 名前付き関係形式、ZW004 |
| G07 pseudo-element | `placeholder:underline` | `before:before:block` — 疑似要素の重複、ZW003 |
| G08 utility | 余白単位がある場合の `-mt-2` | `-p-2` — この群では負の値が使えません、ZW005 |
| G09 named suffix | 余白単位がある場合の `gap-x-1.5` | `w-(10px)` — 禁止された外側の句読記号、ZW001 |
| G10 decimal | 余白単位がある場合の `p-1.5` | `opacity-1.2.3` — 不正な数値、ZW005 |
| G11 fraction or aspect ratio | `w-1/2`、`aspect-4/3` | `w-1/0`、`aspect-2/0` — 分母は正でなければなりません、ZW005 |
| G12 balanced value | `grid-cols-[auto_1fr]` | `w-[calc(1px]` — 区切り記号が対応していません、ZW001 |
| G13 token name | 対応する文字サイズトークンがある場合の `text-2xl` | 設定内の `radii.DEFAULT` — 大文字のトークンキー、ZW007 |
| G14 marker | 単独の `group` マーカー | `hover:group` — マーカーにバリアントは付けられません、ZW004 |
| G15 escape | `bg-[var(--brand\_color)]` | `w-[1px]\` — 末尾のエスケープ、ZW001 |
| G16 catalog root | 余白単位がある場合の `scroll-mt-8` | `ring-2` — 認識されるが未対応の群、ZW004 |
| G17 positive integer | `duration-630` | `w-0/2` — ゼロは正の分数項ではありません、ZW005 |
| G18 configured name | `sm` が設定済みの場合の `sm:block` | `md` がない場合の `md:block`、ZW002 |

候補の角括弧値には、ネストした対応済みの区切り記号、カンマ、コロン、スラッシュ、引用文字列、CSS エスケープ、アンダースコアを含められます。アンダースコアは空白になり、エスケープした `\_` は文字どおりのアンダースコアになります。それ以外のエスケープは CSS エスケープのままです。末尾のエスケープは構文不正です。クラスセレクタのエスケープには、先頭が数字の場合も含め、元の候補のバイト列を使います。

## 値と修飾子

数値形式には ASCII 数字を使います。正の分数は正の整数からなります。サイズ、移動、inset のユーティリティは分数を受け入れ、aspect ユーティリティは括弧なしの正の整数比を受け入れます。色の `/N` は 0～100 の整数 `N` による不透明度修飾子です。`color-mix(in oklab, VALUE N%, transparent)` を出力し、`/0` と `/100` でも同じ関数形式を保ちます。角括弧の色にも同じ修飾子を使えます。サイズまたは inset のスラッシュは不透明度として解釈しません。

負の接頭辞はカタログで許可された群だけに使えます。対象は inset、`auto` を除く margin、子要素間の余白、`auto` を除く z-index、tracking、outline 幅のオフセット、translate、rotate、scroll margin です。padding を含むほかの群では拒否されます。リテラルの長さや数値には先頭のマイナスを 1 つ適用し、負のゼロはゼロに正規化します。リテラル以外には `calc(V * -1)` を出力します。`-p-2` のような未対応の負の値は無効です。

サイズと移動の基部、および7つの inset 基部（`inset`、`inset-x`、`inset-y`、`top`、`right`、`bottom`、`left`）は正の整数分数を受け入れ、`aspect-N/D` は正の整数によるアスペクト比を受け入れます。分子と分母はそれぞれ 1～1,000,000 です。サイズの分数は `calc(100% * N / D)` を出力し、幅と高さの両方を設定します。アスペクト比は比率をそのまま出力するため、`aspect-4/3` は `aspect-ratio: 4 / 3` になります。アスペクト比の括弧なし表記ではゼロや小数を使えません。小数の比率には `aspect-[1.5/2.5]`、カスタムプロパティには `aspect-[var(--project-ratio)]` のような任意値を使ってください。不透明度修飾子は色専用です。`bg-panel/40` は、設定された色を透明色と oklab で 40% の比率で混ぜます。padding やサイズの値には使えません。

inset の分数は各オフセットプロパティに `calc(100% * N / D)` を出力します。`left-1/2` は `left: calc(100% * 1 / 2)`、`-top-1/2` は `top: calc(calc(100% * 1 / 2) * -1)` です。左右のパーセンテージは位置指定要素の包含ブロックの幅、上下は高さを基準にします。

`fontSizes` マップの各項目は必須の `size` と任意の `lineHeight` を持つオブジェクトです。行の高さが指定されると、対になる変数として出力します。その名前が予約されているため、フォントサイズのキーを `-leading` で終わらせることはできません。`ease-in-out` は `easings.in-out` という名前付きの参照です。組み込みのイージングトークンはありません。

角括弧値は空でなく、区切り記号の対応が取れた CSS コンポーネント値で、文字どおりの空白を含められません。ユーティリティ群に対応する CSS プロパティのパーサーで検証されます。空白にはアンダースコアを使い、エスケープしたアンダースコアは文字どおり残ります。値から宣言、セレクタ、コメントを注入することはできません。エスケープや大文字小文字の変種を含め、`url()` は禁止です。

角括弧値では `shadow-[0_1px_3px_var(--shadow-color)]` や `ml-[calc(var(--gap)_+_1px)]` のようにカスタムプロパティを参照できます。各 `var()` は対応が取れていて、カスタムプロパティ名を指定している必要があります。また、値の残りの部分もプロパティに合っていなければならず、`w-[red_var(--x)]` は拒否されます。`var()` に依存する値はカテゴリ未検証として受け付けます。型はブラウザが変数を置き換えて初めて決まるためで、zfb は実行時にそれを検証しません。同じ値の名前付きトークンも同様に扱われます。複数の群が共有する基部では、値全体が変数だと複数の群に当てはまるため、`text-[var(--x)]` や `border-[var(--x)]`（どの辺でも）は曖昧になります。色かサイズかを示す名前付きトークンを使ってください。リテラル値は 1 つの群を選びます。`border-[3px]` は幅、`border-[red]` は色を設定します。どの群も値を受け付けない場合、エラーは検証したすべてのプロパティを挙げます。

データ型ヒントの構文はありません。`text-[color:var(--x)]` は `color:` ヒントが未対応であると報告します。`calc()` の中では、CSS は `+` と `-` の前後に空白を必要とし、これはアンダースコアで書きます。`w-[calc(100vw-2rem)]` のような値では、その綴りで解決できる場合に `w-[calc(100vw_-_2rem)]` を提案します。変数名のハイフンや単項の符号は変更しません。

先頭または末尾の `!` による important 表記は ZW004 で拒否されます。`[overflow-wrap:anywhere]` のような任意プロパティも ZW004 で拒否されます。そのような宣言は手書きの CSS に記述してください。`aria-pressed:block`、`data-[state=open]:block` などの属性バリアントや、`[&_a]:underline` などの任意セレクタバリアントも ZW004 で拒否されます。これらの関係には手書きのセレクタを使ってください。

## 有限のユーティリティカタログ

v1 は有限の集合としてカタログを受け入れます。群には表示、配置、inset、フレックスコンテナと項目、グリッド、整列、サイズ、内側と外側の余白、間隔、子要素間の余白、オーバーフロー、z-index、フォントファミリー・ウェイト・サイズ、行の高さ、字間、テキスト配置と装飾、文字色と背景色、ボーダー幅・色・線種、角丸、区切り線の幅・色、アウトライン幅・色・線種、シャドウ、不透明度、トランジション、時間、イージング、移動、回転、操作、リスト、アスペクト比、スクロール余白、その他のレイアウト補助、テキスト装飾の色、下線のオフセット、表示状態が含まれます。

見慣れた接頭辞でも、意図的に未対応のものがあります。ring、animation、scale、transform、任意プロパティのユーティリティは手書きの CSS に記述します。`ring-*` と `animate-*` の基部は認識されるため、無効な試行には未対応言語の診断が出ます。zudo-wind は animation のキーフレームを合成しません。

仕様リビジョン 4 では、`wrap-anywhere`、`decoration-<color>`、`leading-none`、`cursor-col-resize` などのリサイズ用カーソル、`visible` と `invisible`、`underline-offset-<n>` の 6 つの小さなグループを追加しました。`leading-none` は、プロジェクトが `lineHeights.none` トークンを設定していない場合にだけ定数 `1` を出力します。トークンを設定している場合はトークンが優先されます。`underline-offset-<n>` は整数のピクセル値か、0 以上の任意の長さを受け付けます。これらのユーティリティはいずれも負の値の形を受け付けません。ring と animation のユーティリティは引き続き未対応です。

仕様リビジョン 5 は接尾辞のない `outline` を追加し、幅 1px と実線の style を出力します。数値の `outline-2` は 2px のままで、`focus-visible:outline focus-visible:outline-2` は決定的な順序によって計算上の幅が 2px になります。

リビジョン 6 は自身、group、peer の状態に `checked` を追加し、group の順位を 1～10、peer を 11～20 に変更しました。

リビジョン 7 は `selection` と `pointer-coarse`／`pointer-fine` を追加しました。pointer は正規順で関係バリアントより前です。

リビジョン 8 は `decoration-<整数>` → `text-decoration-thickness: <n>px`、0 以上の長さの `decoration-[<length>]`、`decoration-solid`／`double`／`dotted`／`dashed`／`wavy` → text-decoration-style を追加しました。既存の色と `/N` 不透明度は残ります。`decoration-auto` と `decoration-from-font` は未対応のキーワードで、thickness/style の負数とスラッシュ形式は拒否します。設定済みの完全な色トークンは style の基部より優先され、`colors.wavy` があれば `decoration-wavy` は色になります。`decoration-[var(--x)]` は曖昧で ZW005、`color:`／`length:` ヒントは未対応です。

リビジョン 9 は `help`、`none`、`progress`、`crosshair`、`cell`、`copy`、`alias`、`no-drop`、`context-menu`、`vertical-text`、`all-scroll`、`zoom-in`、`zoom-out` の13のカーソルキーワードを追加しました。cursor は引き続きキーワード専用で、トークン、負数、スラッシュ、任意値は使えません。

リビジョン 10 は7つの inset 基部に分数を追加し、リビジョン 11 は固定キーワードの `justify-self`、`justify-items`、`place-self`、`place-content` を追加しました。リビジョン 12 は定数 `translate-x-px` と `translate-y-px` を追加し、それぞれの軸変数に 1px を出力します（負数形は -1px）。`px` はテーマトークンではなく言語定数です。現在のカタログは spec 1 revision 12 です。

`space-x/y` は後続の表示対象の直接の子に margin-left または margin-top を設定し、`divide-x/y` は実線の左または上のボーダーを設定します。セレクタは `C > :not([hidden]) ~ :not([hidden])` で、`C` は完全なユーティリティの対象セレクタです。両側の兄弟要素を `hidden` 属性で絞ります。その属性を持たず `display: none` になっている要素は調べません。逆方向フラグはなく、表示上の順序も推測しません。疑似要素バリアントはこれらの子ユーティリティと組み合わせられません。たとえば `before:divide-y` は子セレクタが誤った対象を指すため、R23/ZW005 で拒否されます。

トランジション系ユーティリティは 150ms の時間を設定し、`wind.defaultTransitionTimingFunction` を使います。デフォルトは `ease` です。`transition-none` が設定するのは `transition-property: none` だけです。設定値は CSS のタイミング関数です。同じバリアント区画では、後に並ぶ duration と easing のユーティリティがトランジションの宣言を上書きするため、明示した `ease-*` が優先されます。移動のユーティリティは個別の `translate` プロパティと、登録された `--zw-translate-x` / `--zw-translate-y` カスタムプロパティで合成されます。登録は `<length-percentage>` 構文を使い、継承せず、初期値は `0px` です。各軸のユーティリティは対応する変数と合成された移動値を設定します。回転には独立した `rotate` プロパティを使います。ring、animation、scale、transform 文字列のユーティリティはカタログの対象外です。
