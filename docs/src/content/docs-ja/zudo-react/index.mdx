zudo-react は zfb に同梱される JSX ランタイムです。v1 では signal と computed 値によるリアクティビティ、スコープに属する effect、サーバーレンダリング、DOM のハイドレーションを提供します。rawHtml、Show、For は明示的な API です。React や Preact の hooks および互換レイヤーはありません。以下のページでは JSX、リアクティビティ、ライフサイクル、フォーム、Preact hooks からの移行を説明します。
