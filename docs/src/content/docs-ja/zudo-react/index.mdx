zudo-react は zfb に同梱される JSX ランタイムです。v1 では signal と computed 値によるリアクティビティ、スコープに属する effect、サーバーレンダリング、DOM のハイドレーション、アイランド専用のテストエントリを提供します。rawHtml、Show、For は明示的な API です。React や Preact の hooks および互換レイヤーはありません。以下のページでは JSX、リアクティビティ、ライフサイクル、フォーム、テスト、Preact hooks からの移行を説明します。[テストガイド](./testing.mdx)では Vitest の設定と実際のアイランドのテスト方法を扱います。
