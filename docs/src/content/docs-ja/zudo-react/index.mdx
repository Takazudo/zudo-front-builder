zudo-react は zfb に含まれる JSX ランタイムです。v1 では signal と computed によるリアクティビティ、scope に属する effect、サーバーレンダリングと DOM hydration を提供し、rawHtml、Show、For を明示的な API として備えます。hooks や React、Preact との互換レイヤーはありません。以下のページでは、JSX、リアクティビティ、ライフサイクル、フォーム、Preact hooks からの移行を扱います。
