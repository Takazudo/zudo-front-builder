フロントエンド開発のほとんどを 1 つの CLI で。`zfb new` → `zfb dev` → `zfb check` → `zfb build` → `zfb preview` の順に進めます。ページ、データ、インタラクション、CSS を小さな API で組み合わせます。ビルド時、Worker、ブラウザーでそれぞれ何が動くのかといった全体の組み合わせ方は、[フロントエンド開発者のための zfb 全体像](../architecture/architecture-overview.mdx)で説明しています。

<Note>

完全な TypeScript チェックと Cloudflare のツールには Node.js が必要です。テスト、lint、format、デプロイはプロジェクトのツールで行います。

</Note>
