Almost all everyday frontend development in one CLI: `zfb new` → `zfb dev` → `zfb check` → `zfb build` → `zfb preview`. Compose pages, data, interactivity and CSS with small APIs.

<Note>

Full TypeScript checking and Cloudflare tooling need Node.js. Use your project tools for tests, linting, formatting and deployment.

</Note>
