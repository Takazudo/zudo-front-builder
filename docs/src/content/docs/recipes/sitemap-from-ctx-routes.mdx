## When to reach for this

You want a `sitemap.xml` that mirrors every HTML route your build emitted, with zero per-page bookkeeping. The route manifest already knows every URL; this recipe just stringifies it.

If you also want `lastmod`, `changefreq`, or per-route exclusion, you'll extend the filter — the manifest's per-route `params` are available too.

## The plugin

```ts title="plugins/sitemap.ts"
import { definePlugin } from "@takazudo/zfb/plugins";
import { writeFileSync } from "node:fs";
import { join } from "node:path";

const SITE_URL = process.env.SITE_URL ?? "https://example.com";

export default definePlugin({
  name: "sitemap",
  postBuild({ outDir, routes, logger }) {
    if (!routes) return; // route manifest is absent during preBuild; guard for safety.

    const htmlRoutes = routes.routes.filter((r) => r.extension === "html");

    const xml = [
      '<?xml version="1.0" encoding="UTF-8"?>',
      '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">',
      ...htmlRoutes.map((r) => `  <url><loc>${SITE_URL}${r.url}</loc></url>`),
      "</urlset>",
    ].join("\n");

    writeFileSync(join(outDir, "sitemap.xml"), xml, "utf-8");
    logger.info(`sitemap: wrote ${htmlRoutes.length} URLs`);
  },
});
```

```ts title="zfb.config.ts"
import { defineConfig } from "@takazudo/zfb/config";

export default defineConfig({
  plugins: [{ name: "./plugins/sitemap.ts" }],
});
```

## What you get

After `zfb build`, `dist/sitemap.xml` contains every HTML route:

```xml title="dist/sitemap.xml"
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://example.com/</loc></url>
  <url><loc>https://example.com/blog/hello/</loc></url>
  <url><loc>https://example.com/about/</loc></url>
</urlset>
```

Routes are pre-sorted by `url` in the manifest, so the output is byte-stable across runs.

## Excluding routes

Two clean options:

1. **Filter in the plugin.** Drop URLs by prefix:
   ```ts
   const htmlRoutes = routes.routes
     .filter((r) => r.extension === "html")
     .filter((r) => !r.url.startsWith("/internal/"));
   ```
2. **Per-route opt-out via frontmatter.** Add a `sitemap_exclude` field to your pages and read it from `routes.routes[].source`. The manifest gives you the source module path but not its frontmatter — you'd need a sibling preBuild plugin to stash a `Set<string>` of excluded routes in a virtual module and re-import it here.

For most sites, the prefix filter is enough.

## Tip: prefer a `sitemap.xml.tsx` page if you can

zfb has [non-HTML pages](/docs/concepts/non-html-pages) — you can write `pages/sitemap.xml.tsx` that returns the same XML string, and skip the plugin entirely. The page form participates in normal routing and shows up in the manifest like any other route, which is closer to zfb's grain.

The plugin form survives when you need the *complete* manifest at emission time (e.g. you want the sitemap to enumerate every other route, including dynamic ones, after they've all been generated). That's the case the recipe is really for.
