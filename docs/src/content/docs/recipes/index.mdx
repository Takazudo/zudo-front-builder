## What this section will be

A maintainer-curated set of small, focused patterns for composing zfb's primitives — `addVirtualModule`, `postBuild` plugins, `ctx.routes`, non-HTML pages, MDX components — into concrete solutions you can adapt.

Each recipe will be:

- A single article on a single topic
- Written as an explanation, not a code dump — the _why_ matters as much as the _how_
- Anchored to a specific zfb version range, so you know what state of the engine it assumes

## What this section will not be

- A grab-bag of unverified snippets
- A community-contributed pool (curation matters — see [#348](https://github.com/Takazudo/zudo-front-builder/issues/348) for the discipline rationale)
- A replacement for the [Concepts](/docs/concepts) section, which documents zfb's primitives themselves

When the first recipe lands, this index will turn into a real catalog entry. Until then, this page just reserves the slot.
