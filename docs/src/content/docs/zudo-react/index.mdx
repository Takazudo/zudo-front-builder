zudo-react is the JSX runtime bundled with zfb. Its v1 contract covers signals and computed values, scoped effects, server rendering, DOM hydration, and an isolated island testing entry, with rawHtml, Show, and For as explicit APIs. It has no hooks or React or Preact compatibility layer. The pages below cover JSX, reactivity, lifecycle, forms, testing, and moving from Preact hooks. See the [Testing](./testing.mdx) guide to configure Vitest and exercise real islands.
