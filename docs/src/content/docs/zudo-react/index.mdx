zudo-react is the JSX runtime bundled with zfb. Its v1 contract covers signals and computed values, scoped effects, server rendering, and DOM hydration, with rawHtml, Show, and For as explicit APIs. It has no hooks or React or Preact compatibility layer. The pages below cover JSX, reactivity, lifecycle, forms, and moving from Preact hooks.
