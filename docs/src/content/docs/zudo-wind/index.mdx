zudo-wind is zfb's owned utility CSS engine. Its versioned v1 language compiles a closed set of class candidates from project sources. Projects provide their own tokens; no color palette, spacing unit, or named scale ships by default. The pages below cover configuration, the language, the cascade, and moving from Tailwind.
