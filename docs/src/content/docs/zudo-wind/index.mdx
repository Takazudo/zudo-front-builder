zudo-wind compiles complete class candidates from project source into versioned CSS. Projects choose their own values: v1 has no default palette, spacing unit, named scale, or breakpoints.

## Choose a task

- [Set up a first component](./overview.mdx) with explicit tokens and complete class candidates.
- [Define project colors, spacing, and other values](./tokens.mdx).
- [Check candidate spelling and arbitrary values](./utility-grammar.mdx).
- [Apply responsive, dark, state, relation, and pseudo-element conditions](./variants.mdx).
- [Browse the complete utility index](./utilities/index.mdx) to find a supported class and its CSS behavior.
- [Look up an implemented or missing Tailwind class](./compatibility/index.mdx), with configuration and verification status.

The [configuration guide](./configuration.mdx) covers source discovery and compiler settings. [Coming from Tailwind](./coming-from-tailwind.mdx) lists changed syntax and migration alternatives.
