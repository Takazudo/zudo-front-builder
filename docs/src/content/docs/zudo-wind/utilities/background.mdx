Set an element’s background color independently of its text color.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `bg-panel` | `background-color: var(--zw-color-panel);` |
| `bg-accent/18` | `background-color: color-mix(in oklab, var(--zw-color-accent) 18%, transparent);` |

<Details title={"Example setup"}>

The shared preview base explicitly sets spec 1, reset: "none", strict mode, tokens.spacingUnit: "0.25rem", and no breakpoints. Each named value is configured in that example; there is no inherited palette or theme. wind-demo classes are authored context styles; their CSS is shown separately from the utility declarations.

</Details>

## Custom and named values

A name such as bg-panel must be declared under tokens.colors. The keywords bg-current and bg-transparent are also supported. Arbitrary CSS colors use brackets, for example bg-[#e7f0f5]. Color slash opacity accepts whole-number percentages from 0 through 100 and mixes only the background color with transparent. It does not make the element’s text transparent. No Tailwind palette is assumed.
