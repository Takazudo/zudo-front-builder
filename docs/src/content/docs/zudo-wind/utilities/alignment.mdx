Use alignment utilities on a flex or grid container to position its children. items controls the cross axis, justify controls the main axis in flex, place-items combines both grid item axes, and self overrides one item.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `items-center` | `align-items: center;` |
| `justify-between` | `justify-content: space-between;` |
| `self-end` | `align-self: flex-end;` |
| `place-items-center` | `place-items: center;` |
| `self-start` | `align-self: flex-start;` |

## Custom and named values

These roots accept a fixed keyword set. items and self support start, end, center, baseline, and stretch; justify supports start, end, center, between, around, and evenly; place-items supports start, end, center, and stretch. The container must provide the relevant layout context and available space.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
