## Custom and named values

Named colors such as border-ink must be configured in tokens.colors; there is no default palette. border-current and border-transparent are supported keywords. A color slash modifier accepts an integer from 0 through 100, such as border-x-accent/85. Bracket values accept validated CSS colors. The border, border-x, border-y, and edge forms select physical sides; combine them with a border-width utility to make the color visible. Width and color share class roots, so numeric suffixes mean width while configured color names mean color.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
