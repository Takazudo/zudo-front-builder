Draw a solid border on each later visible direct child to separate grouped items.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `divide-x-3` | `border-left-width: 3px; border-left-style: solid;` |
| `divide-y-2` | `border-top-width: 2px; border-top-style: solid;` |

<Details title={"Example setup"}>

The shared preview base explicitly sets spec 1, reset: "none", strict mode, tokens.spacingUnit: "0.25rem", and no breakpoints. Each named value is configured in that example; there is no inherited palette or theme. wind-demo classes are authored context styles; their CSS is shown separately from the utility declarations.

</Details>

## Custom and named values

divide-y adds a top border to later visible direct siblings; divide-x adds a left border. Both use physical sides, have a bare 1px form, accept integer pixel widths and validated bracket lengths, and set the relevant border style to solid. The first visible child receives no divider. Elements with a hidden attribute are excluded even if they occur between visible children; display:none without hidden is still a selector participant. There are no reverse flags.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
