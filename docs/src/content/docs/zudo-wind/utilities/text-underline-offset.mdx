Move an existing underline away from or toward the text. The offset affects underline placement, not whether an underline is drawn.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `underline-offset-4` | `text-underline-offset: 4px;` |
| `underline-offset-[0.15em]` | `text-underline-offset: 0.15em;` |

## Custom and named values

An integer suffix such as underline-offset-4 means 4px. Arbitrary bracket values can use supported nonnegative lengths such as underline-offset-[0.15em], which scales with the font size. The catalog does not define named offset tokens, percentages, negative values, or an auto keyword for this family. Keep enough distance for the underline to remain associated with the text.
