Choose the typeface stack for an element. Use a named font-family token when the same stack should be reused across a site; use an arbitrary value for a one-off stack.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `font-ui` | `font-family: var(--zw-font-family-ui);` |
| `font-[Georgia,_serif]` | `font-family: Georgia, serif;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. Each token example declares tokens.fontFamilies in its record. No browser theme or Tailwind font token is assumed. wind-demo classes add only spacing, borders, labels, and color; the font utilities supply the typeface.

</Details>

## Custom and named values

A class such as font-reading resolves tokens.fontFamilies.reading. Token names used by font-family and font-weight share the font root, so keep their names distinct in one configuration. An arbitrary stack such as font-[Georgia,_serif] replaces the underscore with a space and is validated as font-family CSS. Prefer a configured name for a stack reused in several places; arbitrary values are useful for a local exception. The selected font still needs to be installed or loaded by the application.
