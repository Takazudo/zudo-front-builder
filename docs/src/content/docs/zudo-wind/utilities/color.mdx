Set the foreground color of text while leaving its background and surrounding layout alone.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `text-ink` | `color: var(--zw-color-ink);` |
| `text-[#8b1e3f]/90` | `color: color-mix(in oklab, #8b1e3f 90%, transparent);` |

<Details title={"Example setup"}>

The shared preview base explicitly sets spec 1, reset: "none", strict mode, tokens.spacingUnit: "0.25rem", and no breakpoints. Each named value is configured in that example; there is no inherited palette or theme. wind-demo classes are authored context styles; their CSS is shown separately from the utility declarations.

</Details>

## Custom and named values

Names such as text-ink resolve only through tokens.colors. The literal keywords text-current and text-transparent are also accepted. Bracket values such as text-[#8b1e3f] are parsed as CSS colors. A slash modifier accepts an integer from 0 to 100 and mixes that color with transparent in Oklab; text-accent/85 therefore fades the color itself. This family has no built-in palette.
