Use width, height and size for direct dimensions; use min- and max- constraints when a box should adapt within bounds. Pair w-full with max-w-* for fluid content that stops growing at a readable measure.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `size-12` | `width: 3rem; height: 3rem;` |
| `h-24` | `height: 6rem;` |
| `w-1/2` | `width: calc(100% * 1 / 2);` |
| `max-w-64` | `max-width: 16rem;` |
| `min-w-0` | `min-width: 0;` |
| `min-h-24` | `min-height: 6rem;` |
| `max-h-32` | `max-height: 8rem;` |
| `size-card` | `width: var(--zw-size-card); height: var(--zw-size-card);` |
| `max-w-reading` | `max-width: var(--zw-size-reading);` |

<Details title={"Example setup"}>

## Custom and named values

The configured spacingUnit is 0.25rem, so numeric forms such as w-16 resolve to 4rem. Values may also use fractions like w-1/2, built-in keywords such as full, min, max, fit, auto, screen or dvh, named tokens from tokens.sizes or tokens.spacing, and arbitrary CSS values like w-[18rem]. size sets width and height together. This preview explicitly configures tokens.sizes.card and tokens.sizes.reading.
