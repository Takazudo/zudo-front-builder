Use position to choose the reference for offsets and whether a box stays in normal flow. relative keeps its place and anchors absolute children; absolute leaves flow, fixed follows the preview viewport, and sticky sticks within a scrolling ancestor.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `static` | `position: static;` |
| `relative` | `position: relative;` |
| `absolute` | `position: absolute;` |
| `sticky` | `position: sticky;` |
| `fixed` | `position: fixed;` |

<Details title={"Example setup"}>

Every preview explicitly starts from spec 1, reset "none", strict mode, spacingUnit "0.25rem", and no breakpoints. Numeric spacing values multiply that unit; no Tailwind theme is inherited. wind-demo classes are authored presentation scaffolding, with their CSS shown beside the exact HTML source.

</Details>

## Custom and named values

The five class names are exact and have no values. Offset utilities such as top-4 only move positioned boxes; static ignores offsets and cannot anchor absolute descendants. Sticky needs a non-auto inset threshold and a scrolling context. A transformed ancestor can also establish a containing block for fixed descendants in CSS.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
