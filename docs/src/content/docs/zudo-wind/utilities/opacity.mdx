Set the opacity of an entire element, including its rendered descendants.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `opacity-55` | `opacity: 0.55;` |
| `opacity-[0.35]` | `opacity: 0.35;` |

## Custom and named values

Integer suffixes are percentages from 0 through 100: opacity-55 emits 0.55 and opacity-100 is fully opaque. Bracket values accept a number from 0 to 1 or a percentage from 0% to 100%. This utility fades the whole element and its children together. Color slash modifiers work differently: they mix only a color property with transparent. Use element opacity carefully around small text and controls because it can reduce contrast.
