Set a flex item's sizing behavior when the container has extra or insufficient room. The flex presets choose combinations of basis, growth and shrink; grow and shrink set those factors independently.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `flex-1` | `flex: 1 1 0%;` |
| `flex-auto` | `flex: 1 1 auto;` |
| `flex-initial` | `flex: 0 1 auto;` |
| `flex-none` | `flex: none;` |
| `grow` | `flex-grow: 1;` |
| `grow-0` | `flex-grow: 0;` |
| `grow-[2]` | `flex-grow: 2;` |
| `shrink` | `flex-shrink: 1;` |
| `shrink-0` | `flex-shrink: 0;` |
| `shrink-[2]` | `flex-shrink: 2;` |
| `basis-auto` | `flex-basis: auto;` |
| `basis-1/2` | `flex-basis: calc(100% * 1 / 2);` |
| `order-first` | `order: -9999;` |
| `order-last` | `order: 9999;` |

## Custom and named values

flex-1 is 1 1 0%, flex-auto is 1 1 auto, flex-initial is 0 1 auto, and flex-none is none. grow and shrink default to 1; the -0 forms use zero, and arbitrary numeric values such as grow-[2] are supported. Give the container display:flex to see the factors take effect.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
