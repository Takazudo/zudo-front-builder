## Custom and named values

Names resolve only through tokens.colors; divide-current and divide-transparent are also supported, as are validated bracket colors. A slash accepts an integer from 0 through 100 and mixes the color with transparent in Oklab. The divide color rule sets all four border-color longhands on matching later siblings; pair it with divide-x or divide-y for line width and direction. Hidden-attribute children are skipped, so the next visible child is still separated from the previous visible child. This is a child-selector utility, not a color applied to the container.
