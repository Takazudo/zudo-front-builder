Control where text aligns, how spaces and line breaks behave, and how long words or single lines fit a container. Start with normal wrapping; use specialized behavior only when the content and available width call for it.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `text-center` | `text-align: center;` |
| `whitespace-pre-wrap` | `white-space: pre-wrap;` |
| `break-all` | `word-break: break-all;` |
| `break-normal` | `overflow-wrap: normal; word-break: normal;` |
| `break-words` | `overflow-wrap: break-word;` |
| `wrap-anywhere` | `overflow-wrap: anywhere;` |
| `truncate` | `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. These examples use fixed demo widths authored in wind-demo CSS so the wrapping behavior is visible; that CSS does not set text alignment, white-space, word-break, overflow-wrap, or truncation. Japanese text wraps at natural character boundaries where the browser allows it.

</Details>

## Custom and named values

text-left, text-center, text-right, text-justify, text-start, and text-end control alignment; start and end follow the element direction. whitespace-* chooses how spaces and source newlines collapse, stay, or wrap. break-all can split at any character, break-words allows an emergency break for a long word, and wrap-anywhere also changes min-content sizing. break-normal restores normal word-break and overflow-wrap. truncate combines hidden overflow, an ellipsis, and no wrapping; give the element a real width constraint or the effect has nothing to trim. For Japanese, normal line breaking already uses character-level opportunities, so compare these controls with long Latin identifiers as well as Japanese prose.
