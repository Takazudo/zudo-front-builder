Use inset utilities to place a positioned box against its containing block. inset sets all four edges, inset-x and inset-y set a pair, and top/right/bottom/left target one edge.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `inset-4` | `top: 1rem; right: 1rem; bottom: 1rem; left: 1rem;` |
| `inset-x-4` | `left: 1rem; right: 1rem;` |
| `inset-y-4` | `top: 1rem; bottom: 1rem;` |
| `top-0` | `top: 0;` |
| `right-0` | `right: 0;` |
| `bottom-0` | `bottom: 0;` |
| `left-0` | `left: 0;` |
| `-top-2` | `top: -0.5rem;` |
| `left-nudge` | `left: var(--zw-spacing-nudge);` |

<Details title={"Example setup"}>

Every preview explicitly starts from spec 1, reset "none", strict mode, spacingUnit "0.25rem", and no breakpoints. Numeric spacing values multiply that unit; no Tailwind theme is inherited. wind-demo classes are authored presentation scaffolding, with their CSS shown beside the exact HTML source.

## Custom and named values

Numeric offsets use the explicitly configured spacingUnit of 0.25rem; 4 is 1rem. The 0, px, full, and auto keywords need no token. Named values such as left-nudge require tokens.spacing; arbitrary values such as top-[calc(100%_+_8px)] are also supported. Negative forms are supported, for example -top-2. Offsets do not make an element positioned.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
