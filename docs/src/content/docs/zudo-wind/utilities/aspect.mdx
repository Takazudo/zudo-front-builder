Use aspect-ratio to preserve a frame shape while its width changes, which is useful for media cards, thumbnails, and embeds. The ratio determines the other dimension when that dimension is automatic.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `aspect-video` | `aspect-ratio: 16 / 9;` |
| `aspect-square` | `aspect-ratio: 1 / 1;` |
| `aspect-3/2` | `aspect-ratio: 3 / 2;` |
| `aspect-auto` | `aspect-ratio: auto;` |
| `aspect-4/3` | `aspect-ratio: 4 / 3;` |

## Custom and named values

The named values are auto, square (1:1), and video (16:9). Numeric fractions such as aspect-3/2 are supported, as are arbitrary CSS values in brackets. No aspect token is inherited or required. aspect-auto leaves the ratio automatic so another sizing rule or intrinsic content can determine the shape.
