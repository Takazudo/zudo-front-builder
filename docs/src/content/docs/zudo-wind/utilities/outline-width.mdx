Set the outline thickness and its distance from the element.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `outline-2` | `outline-width: 2px; outline-style: solid;` |
| `outline-offset-4` | `outline-offset: 4px;` |

## Custom and named values

outline-2 uses pixels and sets a solid outline style along with the width. Bracket values accept validated CSS lengths. outline-offset-4 sets a 4px gap between the outline and the element; offset accepts integer pixels or an arbitrary length and may be negative. Outline does not take up layout space. Width and offset are separate catalog entries, so tune them independently. Keep a visible focus indicator on interactive controls.
