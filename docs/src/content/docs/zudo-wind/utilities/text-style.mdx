Change the line decoration, letter case, or font treatment without changing the words in the source. These utilities affect different CSS properties, so combine them only when each behavior is intentional.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `underline` | `text-decoration-line: underline;` |
| `overline` | `text-decoration-line: overline;` |
| `line-through` | `text-decoration-line: line-through;` |
| `no-underline` | `text-decoration-line: none;` |
| `uppercase` | `text-transform: uppercase;` |
| `lowercase` | `text-transform: lowercase;` |
| `capitalize` | `text-transform: capitalize;` |
| `normal-case` | `text-transform: none;` |
| `italic` | `font-style: italic;` |
| `not-italic` | `font-style: normal;` |
| `tabular-nums` | `font-variant-numeric: tabular-nums;` |
| `antialiased` | `-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. The examples apply each class directly to the text whose behavior it demonstrates. The scaffold adds only layout, borders, spacing, and inherited link color. Case transforms change Latin letters but do not case-convert Japanese kana or kanji.

</Details>

## Custom and named values

Underline, overline, line-through, and no-underline set text-decoration-line. The four case utilities set text-transform, where normal-case restores none. italic and not-italic set font-style. tabular-nums requests tabular numeric glyphs, which only show when the chosen font supports them. antialiased sets platform-specific font-smoothing properties; browser and operating-system rendering can make the visual difference subtle. This family has fixed classes rather than named value tokens.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
