Move an element along the horizontal or vertical axis without changing the space it occupies in layout. The two axes compose on the same element.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `translate-x-8` | `--zw-translate-x: 2rem; translate: var(--zw-translate-x) var(--zw-translate-y);` |
| `translate-y-4` | `--zw-translate-y: 1rem; translate: var(--zw-translate-x) var(--zw-translate-y);` |

<Details title={"Example setup"}>

Every preview explicitly uses spec: 1, reset: "none", strict mode, spacingUnit: "0.25rem", no breakpoints, and defaultTransitionTimingFunction: "ease". This makes translate-x-8 equal 2rem and translate-y-4 equal 1rem. One preview adds the named spacing token rail: 2rem. The diagrams use authored CSS only for the stage, anchor, and square; zudo-wind utilities supply the movement and rotation.

</Details>

## Custom and named values

Numeric suffixes use tokens.spacingUnit when configured. A named value such as translate-x-rail comes from tokens.spacing; fractions such as translate-y-1/2 are percentages of the element, and square-bracket values can provide a one-off CSS length. The fixed values 0 and full mean 0 and 100%. Negative forms are supported. No Tailwind spacing scale is inherited.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
