Use z-index to order overlapping positioned boxes within their stacking context. A larger number paints above a smaller one when the elements participate in the same context.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `z-10` | `z-index: 10;` |
| `z-auto` | `z-index: auto;` |
| `z-0` | `z-index: 0;` |
| `z-dialog` | `z-index: var(--zw-z-dialog);` |
| `-z-[1]` | `z-index: -1;` |

## Custom and named values

Integer values, negative forms such as -z-10 and -z-[1], auto, named tokens in tokens.zIndices, and arbitrary CSS values such as z-[42] are supported. Put the negative prefix before the bracketed value; a signed number inside brackets is rejected. This preview declares tokens.zIndices.dialog as 30, so z-dialog is a readable project layer name. z-index does not move an element or necessarily escape an ancestor stacking context.
