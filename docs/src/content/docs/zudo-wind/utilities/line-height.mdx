Control the distance between lines of text. A compact leading suits short labels and larger headings; a more open value can make body copy easier to follow.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `leading-copy` | `line-height: var(--zw-leading-copy);` |
| `leading-[1.8]` | `line-height: 1.8;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. Each token example declares tokens.lineHeights. The named copy and compact values are ratios, while leading-[1.8] is an arbitrary ratio. No font-size token is implied by a leading utility.

</Details>

## Custom and named values

Use a name such as leading-copy when a ratio belongs to a reusable text role. leading-none emits the configured lineHeights.none token when one exists and otherwise falls back to 1. Arbitrary bracket values accept validated line-height CSS such as a unitless ratio or length. Line height inherits, so apply it at the smallest block that should share the rhythm.
