Apply a configured box shadow, an arbitrary CSS box-shadow, or remove the shadow.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `shadow-panel` | `box-shadow: var(--zw-shadow-panel);` |
| `shadow-[0_12px_24px_#16324f33]` | `box-shadow: 0 12px 24px #16324f33;` |

## Custom and named values

A named value such as shadow-panel resolves only from tokens.shadows. shadow-none is the supported keyword for no shadow. Bracket values are validated as CSS box-shadow values, with underscores separating spaces in a class candidate. There is no default shadow scale and no shadow opacity modifier. The catalog does not add ring utilities.
