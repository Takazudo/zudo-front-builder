Choose whether oversized content is clipped, visible, or scrollable. Use x/y forms when each axis needs a different rule. Overscroll utilities decide whether a scroll gesture can chain from an inner scroller to its parent at an edge.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `overflow-auto` | `overflow: auto;` |
| `overflow-hidden` | `overflow: hidden;` |
| `overflow-clip` | `overflow: clip;` |
| `overflow-visible` | `overflow: visible;` |
| `overflow-scroll` | `overflow: scroll;` |
| `overflow-x-auto` | `overflow-x: auto;` |
| `overflow-x-scroll` | `overflow-x: scroll;` |
| `overflow-y-scroll` | `overflow-y: scroll;` |
| `overflow-y-auto` | `overflow-y: auto;` |
| `overscroll-auto` | `overscroll-behavior: auto;` |
| `overscroll-none` | `overscroll-behavior: none;` |
| `overscroll-contain` | `overscroll-behavior: contain;` |
| `overscroll-x-contain` | `overscroll-behavior-x: contain;` |
| `overscroll-y-contain` | `overscroll-behavior-y: contain;` |

## Custom and named values

overflow accepts auto, hidden, clip, visible, and scroll; the x/y forms accept the same values. auto adds scrolling only when needed, while scroll requests a scroll container even when content fits. overscroll accepts auto, contain, or none on both or one axis. These utilities have fixed keywords and no token or arbitrary values.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
