Choose display to control whether an element joins the text flow, starts a block, or arranges its children as flex or grid items. Use inline-block when an inline element also needs a box size; use hidden when the box should leave layout.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `inline` | `display: inline;` |
| `inline-block` | `display: inline-block;` |
| `block` | `display: block;` |
| `flex` | `display: flex;` |
| `inline-flex` | `display: inline-flex;` |
| `grid` | `display: grid;` |
| `inline-grid` | `display: inline-grid;` |
| `hidden` | `display: none;` |

## Custom and named values

This family has eight exact class names and no value suffixes or custom values. inline, block, inline-block, flex, inline-flex, grid, inline-grid, and hidden map directly to display modes. hidden is display:none; invisible is a separate visibility utility that preserves the box.
