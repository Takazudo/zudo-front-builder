Use grid-template utilities to define rows and columns, then place children by spanning tracks or choosing their start and end lines. Grid works well for two-dimensional layouts where both axes matter.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `grid-cols-3` | `grid-template-columns: repeat(3,minmax(0,1fr));` |
| `grid-rows-2` | `grid-template-rows: repeat(2,minmax(0,1fr));` |
| `col-span-2` | `grid-column: span 2 / span 2;` |
| `col-start-2` | `grid-column-start: 2;` |
| `col-end-4` | `grid-column-end: 4;` |
| `row-span-2` | `grid-row: span 2 / span 2;` |
| `row-start-2` | `grid-row-start: 2;` |
| `row-end-4` | `grid-row-end: 4;` |
| `grid-cols-[7rem_1fr]` | `grid-template-columns: 7rem 1fr;` |
| `grid-rows-[auto_1fr]` | `grid-template-rows: auto 1fr;` |
| `col-start-auto` | `grid-column-start: auto;` |
| `row-end-auto` | `grid-row-end: auto;` |

## Custom and named values

grid-cols-N and grid-rows-N accept integers from 1 through 12; none and subgrid are also supported. col-span-N and row-span-N accept 1 through 12, while start/end line numbers accept 1 through 13 and auto. span-full maps to 1 / -1. Template utilities also accept arbitrary CSS track lists; encode spaces with underscores, for example grid-cols-[7rem_1fr].

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
