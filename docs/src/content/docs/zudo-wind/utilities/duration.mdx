Set how long a transition takes. Duration does not choose which property changes, so pair it with a transition utility and a state change.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `duration-150` | `transition-duration: 150ms;` |

<Details title={"Example setup"}>

Every preview explicitly uses spec: 1, reset: "none", strict mode, spacingUnit: "0.25rem", no breakpoints, and defaultTransitionTimingFunction: "ease". The buttons move only 8px on hover or focus-visible, and the longest sample is 420ms. Authored demo CSS sets transition time to zero for prefers-reduced-motion: reduce.

</Details>

## Custom and named values

An integer suffix is interpreted as milliseconds from 0 through 60000, so duration-300 means 300ms and duration-0 disables interpolation. Use duration-[420ms] for a one-off CSS time. Duration has no named token scale. The default 150ms comes from transition utilities; adding duration-* overrides that value.
