Change the color of an existing underline, overline, or other text decoration while leaving the text color alone. Put the utility on an element that has a visible decoration.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `decoration-accent` | `text-decoration-color: var(--zw-color-accent);` |
| `decoration-[#b42318]/80` | `text-decoration-color: color-mix(in oklab, #b42318 80%, transparent);` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. The named example declares tokens.colors.accent. Authored CSS sets a readable text color and preserves the browser’s link underline; it does not set text-decoration-color.

</Details>

## Custom and named values

decoration-accent resolves through tokens.colors.accent. decoration-current uses the element’s current text color, and decoration-transparent keeps the decoration geometry while hiding its color. Arbitrary colors such as decoration-[#b42318] are validated by the color parser; a supported opacity modifier such as /80 mixes the color with transparency. This family has no automatic palette: every named color must be configured.
