Use visibility to hide an element while preserving its place in layout, or make it visible again. Choose hidden from the display family when the box should be removed and following content should move into its place.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `invisible` | `visibility: hidden;` |
| `visible` | `visibility: visible;` |

## Custom and named values

This family has two exact class names and no custom values: visible sets visibility:visible and invisible sets visibility:hidden. The box keeps its layout space, while visibility:hidden content is generally omitted from the accessibility tree and cannot be interacted with. hidden is a separate display:none utility.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
