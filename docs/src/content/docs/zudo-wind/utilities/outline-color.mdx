Color an outline independently of its thickness, distance, and line style.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `outline-focus/90` | `outline-color: color-mix(in oklab, var(--zw-color-focus) 90%, transparent);` |
| `outline-[#8b1e3f]` | `outline-color: #8b1e3f;` |

<Details title={"Example setup"}>

The shared preview base explicitly sets spec 1, reset: "none", strict mode, tokens.spacingUnit: "0.25rem", and no breakpoints. Each named value is configured in that example; there is no inherited palette or theme. wind-demo classes are authored context styles; their CSS is shown separately from the utility declarations.

</Details>

## Custom and named values

Named outline colors use tokens.colors; outline-current and outline-transparent are supported keywords. Arbitrary values such as outline-[#8b1e3f] are validated as CSS colors. A slash modifier accepts an integer from 0 through 100 and mixes the color with transparent in Oklab. The outline root is shared: integer suffixes resolve as width, while configured color names and CSS colors resolve as color. No automatic color palette is provided.
