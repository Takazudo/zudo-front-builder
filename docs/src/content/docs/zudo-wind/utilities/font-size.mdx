Set the size of text for a role such as a caption, paragraph, or heading. A configured font-size token can pair size with its own line height; an arbitrary size lets one element use a validated CSS value.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `text-copy` | `font-size: var(--zw-font-size-copy); line-height: var(--zw-font-size-copy-leading);` |
| `text-[20px]` | `font-size: 20px;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. Each example declares tokens.fontSizes with size and lineHeight values. A named text token emits both properties when its lineHeight is present; the arbitrary text-[20px] sample emits font-size only. wind-demo supplies borders and spacing, not typography.

</Details>

## Custom and named values

Use text-copy for a configured token or text-[20px] for a one-off CSS font-size. Named font-size keys share the text root with colors, so the configuration must keep those token names disjoint. Paired leading is part of the configured font-size token; an arbitrary size without slash syntax does not invent a line height. Choose line height separately when the surrounding text needs a specific rhythm.
