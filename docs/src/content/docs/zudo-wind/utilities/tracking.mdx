Adjust the spacing between letters. Slightly tight tracking can suit a short display label, while neutral or open spacing is often easier to read in longer passages.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `tracking-tight` | `letter-spacing: var(--zw-tracking-tight);` |
| `tracking-[0.12em]` | `letter-spacing: 0.12em;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. Each example declares tokens.letterSpacings. wind-demo only supplies a border, wrapping safety, labels, and color; the tracking classes control letter spacing.

</Details>

## Custom and named values

tracking-tight resolves through tokens.letterSpacings.tight. Negative values are supported and can pull letters closer together. Arbitrary values such as tracking-[0.12em] are validated as letter-spacing CSS. Use modest changes: wide tracking can make paragraphs and Japanese text harder to read, so reserve it for short labels or deliberate display treatments.
