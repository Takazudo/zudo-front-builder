## Custom and named values

Named values resolve through tokens.radii; rounded-card is configured as 0.75rem and rounded-pill as 9999px. The built-in keywords rounded-none and rounded-full map to 0 and 9999px. Bracket values such as rounded-[18px] accept validated CSS lengths. Side names are physical: t, r, b, and l select top, right, bottom, and left; two-letter forms select one corner. Values cannot be negative. No default radius scale is inherited.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
