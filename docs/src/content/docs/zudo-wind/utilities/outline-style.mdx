## Custom and named values

The exact classes outline-solid, outline-dashed, outline-dotted, outline-double, and outline-none set outline-style. They do not supply width or color, so pair a visible style with outline width and color utilities. outline-none removes the outline completely; use it only when another clear focus indicator replaces it. The catalog does not include Tailwind’s outline-hidden utility.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
