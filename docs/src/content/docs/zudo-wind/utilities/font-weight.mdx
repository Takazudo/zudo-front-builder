Control how heavy the glyph strokes appear without changing the selected font family or size. Choose a named weight for a reusable role and an arbitrary numeric weight for a value outside that scale.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `font-medium` | `font-weight: var(--zw-font-weight-medium);` |
| `font-[550]` | `font-weight: 550;` |

<Details title={"Example setup"}>

The shared preview base explicitly selects spec 1, reset none, strict mode, spacingUnit 0.25rem, and no breakpoints. Each example configures tokens.fontWeights with regular 400, medium 500, and strong 700. wind-demo classes style only labels and borders; they do not set font weight.

</Details>

## Custom and named values

font-medium resolves through tokens.fontWeights.medium. A class such as font-[550] supplies a validated arbitrary font-weight value. The browser can only show weights supported by the chosen font; synthetic bolding and variable-font axes can change the appearance.
