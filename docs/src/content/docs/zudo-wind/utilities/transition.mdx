Choose which CSS properties change smoothly when a state or value changes. Pair a transition utility with state variants such as hover or focus-visible on a real control.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `transition-colors` | `transition-property: color,background-color,border-color,outline-color,text-decoration-color,fill,stroke; transition-duration: 150ms; transition-timing-function: ease;` |

<Details title={"Example setup"}>

Every preview uses spec: 1, reset: "none", strict mode, an explicit spacingUnit of "0.25rem", no breakpoints, and defaultTransitionTimingFunction: "ease". Transition utilities other than transition-none set 150ms and use that configured timing function. Buttons respond to both pointer hover and keyboard focus. The authored demo CSS removes transition time when prefers-reduced-motion is reduce; the utility examples use only short, user-triggered changes.

</Details>

## Custom and named values

transition, transition-all, transition-colors, transition-opacity, transition-shadow, transition-transform, and transition-none are the supported keywords. A one-off property list can use an arbitrary form such as transition-[border-color]. No named transition-property tokens are built in. transition-none emits only transition-property: none, so it does not set the default duration or easing.
