Use gap on a grid or flex container to separate its items. It adds space between tracks or items without adding padding around the container.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `gap-4` | `column-gap: 1rem; row-gap: 1rem;` |
| `gap-x-8` | `column-gap: 2rem;` |
| `gap-y-2` | `row-gap: 0.5rem;` |
| `gap-gutter` | `column-gap: var(--zw-spacing-gutter); row-gap: var(--zw-spacing-gutter);` |
| `gap-[18px]` | `column-gap: 18px; row-gap: 18px;` |

<Details title={"Example setup"}>

These examples explicitly use spacingUnit: "0.25rem", reset: "none", strict mode and no breakpoints. Numeric suffixes multiply that unit: gap-4 emits literal 1rem lengths. No Tailwind spacing scale or theme is inherited. wind-demo classes are authored demonstration scaffolding; their CSS is visible with each preview.

</Details>

## Custom and named values

gap-0 removes gaps and gap-px uses 1px without a spacing token. Other numeric suffixes need tokens.spacingUnit. Named spacing values need tokens.spacing, as the gutter example shows; arbitrary values such as gap-[18px] do not need that scale. Gap values cannot be negative. Use underscore encoding for spaces in arbitrary calc values. gap-x sets column-gap and gap-y sets row-gap; in flex layouts, how these affect item and line spacing follows the flex direction.
