Adjust the small browser behaviors around native controls: accent color, pointer targeting, cursor feedback, resizing, and text selection. These classes complement semantic HTML; they do not replace control behavior or labels.

## Quick reference

| Example class | Expected declarations |
| --- | --- |
| `accent-brand` | `accent-color: var(--zw-color-brand);` |
| `cursor-pointer` | `cursor: pointer;` |
| `pointer-events-none` | `pointer-events: none;` |
| `resize-y` | `resize: vertical;` |
| `select-all` | `user-select: all;` |

<Details title={"Example setup"}>

Every preview explicitly uses spec: 1, reset: "none", strict mode, spacingUnit: "0.25rem", no breakpoints, and defaultTransitionTimingFunction: "ease". The settings example configures tokens.colors.brand for the checkbox accent. Checkboxes, buttons, a search input, code text, and a textarea keep their native keyboard and pointer behavior.

</Details>

## Custom and named values

The accent utility accepts a configured colors token such as accent-brand, the fixed values transparent and current, or a valid arbitrary color. Cursor, pointer-events, resize, and select use finite catalog keywords; they have no inherited named theme values. pointer-events-none on the decorative search glyph lets the pointer reach the underlying input. Use disabled on an actually unavailable button as well as a not-allowed cursor.

**Related guides:** [Utility grammar](../utility-grammar.mdx) · [Variants](../variants.mdx)
