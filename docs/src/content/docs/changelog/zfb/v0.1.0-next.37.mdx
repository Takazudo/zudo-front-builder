# v0.1.0-next.37

Released: 2026-06-09

A small CLI ergonomics release: bare `--host` (no value) on `zfb dev` / `zfb preview` is now a Vite-style shortcut for `0.0.0.0`, restoring the one-keystroke "expose to the LAN" flag.

## Features

- Allow bare `--host` (no value) to mean `0.0.0.0` for dev/preview (#891) (118d560)
