# v2.17.0

Released: 2026-09-14

- Bump the YAML frontmatter parser to `noyalib-serde-yaml` 0.0.43 (6077d0bd, 9291958e).
  The `serde_yaml` package alias moves from 0.0.31 to 0.0.43 with no production source
