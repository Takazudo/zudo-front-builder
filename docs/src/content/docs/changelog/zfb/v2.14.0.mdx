# v2.14.0

Released: 2026-08-30

## Other Changes

- Update directive-name boundaries to Unicode 16.0.0: newer punctuation and
  symbols now end names, while U+111C9 no longer does.
- Preserve GFM autolink literals containing ports during generic directive
  scanning, so full URLs and non-overlapping sibling ranges reach consumers.
