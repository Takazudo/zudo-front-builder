# v5.0.0

Released: 2026-10-23

## Breaking Changes

- Generated projects depend on `@takazudo/zfb` 5.0.0, which requires Node.js 24 (ae87cd20). Run the generated project's install and build on Node 24 or newer. The `create-zfb` CLI itself still runs on Node 18 or newer.
