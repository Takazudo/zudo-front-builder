# v3.0.0

Released: 2026-09-30

## Breaking Changes

- Generate projects with zudo-react JSX and zudo-wind styles instead of Preact and Tailwind (09caf5ea). Existing generated projects must migrate their own configuration and components.

## Features

- Give the basic-blog scaffold explicit zudo-wind tokens, dark selector, and `owned-v1` reset, with prose styles for that reset (8f771e88).
