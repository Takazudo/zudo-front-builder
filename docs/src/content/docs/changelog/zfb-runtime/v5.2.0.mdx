# v5.2.0

Released: 2026-11-03

## Bug Fixes

- Preserve native form targets and methods, and retry failed fetch prefetches (23a90ab79).
- Honor native link targets and resolve form action URLs against the document base (0fe8defd9).
- Supersede pending navigation on same-document null-state history traversal (2bedd07a9).
- Settle completed fragment navigation before native traversal to avoid spurious abort events (7684db31d).
