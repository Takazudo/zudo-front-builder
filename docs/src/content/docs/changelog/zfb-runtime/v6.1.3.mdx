# v6.1.3

Released: 2026-11-13

## Other Changes

- v6.1.3 is the first complete npm release since 6.0.1. v6.1.0 and v6.1.1 were tagged on GitHub but never reached npm, and v6.1.2 reached npm without `@takazudo/zfb-linux-arm64-gnu`, so 6.1.2 does not install on Linux arm64; use 6.1.3. Read the v6.1.0 notes in this changelog or on the v6.1.0 GitHub Release when upgrading from 6.0.1 (2c9fe076c).
