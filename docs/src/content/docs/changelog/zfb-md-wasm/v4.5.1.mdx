# v4.5.1

Released: 2026-10-15

## Bug Fixes

- `compile` and `renderHtml` now unwrap paragraph-wrapped rows and sections in explicit MDX `<table>` markup, the same fix as in the `@takazudo/zfb` engine. A table like `<thead><tr><th>A</th></tr></thead>` compiles to `table > thead > tr` and renders without `ZR_PARSER_CONTEXT`. `parseToAst` still returns the raw markdown-rs tree, as documented, so `toMdastRoot(parseToAst(...))` stays valid mdast for these tables (5fb773fc, b04bb22b).

## Other Changes

- Shipped sizes: the root (`.`) and `./render` artifacts grow with the table pass. Root goes from 1,521,735 B to 1,522,071 B gzip-9, and `./render` from 1,094,951 B to 1,095,081 B gzip-9. `./highlight` and `./parse` keep their byte sizes. All four `.wasm` artifacts also embed `ZFB_RELEASE_VERSION`, so all four SHA-256 digests change in v4.5.1, including the two whose sizes did not move. Re-verify pinned digests against `@takazudo/zfb-md-wasm/shipped-artifacts.json` or the `zfb-md-wasm-4.5.1-shipped-artifacts.json` Release asset (06182501).
