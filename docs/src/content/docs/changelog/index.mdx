# Changelog

This section tracks released versions of `@takazudo/zfb` and its lockstep workspace packages
(`@takazudo/zfb-runtime`, `@takazudo/zfb-adapter-cloudflare`, `create-zfb`, and the five
platform binaries).

Each version has its own page below, sorted newest-first.

## Release process (internal)

Maintainers use the `/l-make-release` Claude Code skill to bump versions and write entries
in this section. See the skill's SKILL.md for the full flow.

The Mac x86_64 build is optional via the `/l-make-mac-release-binary` skill — if the user
pre-uploads the archive to the draft GH Release before publishing it, `release.yml` skips
the slow `macos-13` CI leg.
