## openQuestions
  - Layering conflict: zudo-doc requires utilities to be UNLAYERED so they beat its layered flow rule. The handoff places utilities in a layer. Which side changes?
  - Reset: adopt an owned reset equivalent to what zudo-doc depends on (universal margin reset, border defaults, list markers, inherited link color, root font family), or rewrite content.css and the component token rules around minimal-v1?
  - Token source: keep tokens in CSS with an owned replacement for the three @theme block flavours and the namespace wipe, or move them into zfb config so zudoDoc() injects them? The library currently ships tokens to consumers as a CSS file and lets consumers override with a later block.
  - Package class sources: what replaces the generated @source inline safelist so a consumer build emits utilities used inside node_modules/@takazudo/zudo-doc?
  - Does the zfb css standalone command survive with the new engine? The library's published compiled.css is built by it.
  - Group and peer variants are 86 occurrences. Add them to the grammar or convert the call sites to authored CSS?
  - Color opacity modifier: support /N on color tokens (33 occurrences) or define explicit translucent tokens?
  - Dead classes: should the new engine diagnose rounded (62 sites across both repos), ease-in-out, animate-spin, animate-pulse, max-w-sm, md:grid-cols-2 and similar, or start emitting CSS for them and change rendering?
  - Token name DEFAULT (radius) is uppercase and used by 2 utilities; the handoff restricts token names to lowercase.
  - Show and For are required by 9 of 19 islands. Are they in the first deliverable?
  - Raw HTML: what is the trusted escape hatch for script, style and markup strings, and may it appear inside a hydrated island (11 of the 38 sites do)?
  - Reactive side effects: 51 effects exist and many re-run on state change. Does the runtime ship a scope-owned reactive subscription from the start?
  - Forms: select and radio are used by the showcase generator and the zfb docs playgrounds. Extend v1, or rewrite those as uncontrolled forms?
  - Components are called as plain functions in at least 30 places. How does a function call receive a scope?
  - Is there a documented non-JSX descriptor constructor and child-inspection API, or must mdx-components and Tabs be rewritten?
  - The design token panel package peers on Preact and bundles a Tailwind browser runtime. Does it get rewritten, or may it keep a private Preact copy after zfb drops Preact?
  - Two islands render nothing and exist only to pull a script into the bundle. Will zfb provide a plain client-entry mechanism so they can be deleted?
  - This census reflects zudo-doc 5.25.0. The zfb docs site consumes 5.27.0. Should the checkout be updated and the census re-run before the migration table is frozen?
