  - Drift guard invariant: sorted(PUBLISHED_PACKAGES) == sorted(non-private names under packages/* and crates/*/npm) == sorted(_tag_with_retry entries in advance-latest-dist-tag.sh).
  - #[ignore] taxonomy: exactly 5 prefixes (env-gate, heavy, flaky, verification, pending-feature); env-gate and heavy must be reachable by exam.yml exact name or a health.yml scope; verification and pending-feature are exempt.
  - nextest registration rule (crates/CLAUDE.md:46): a binary that spawns zfb dev/build/preview or boots V8/esbuild in-process joins the filter, the file's header comment, and the CLAUDE.md buckets in one commit. Groups are max-threads=1 with slow-timeout 120s x 5.
  - Retry budget: local 0; CI profile retries = 1 with pass-on-retry recorded as FLAKY. Timeouts are guardrails; raising them needs a linked issue and measured distribution.
  - Five-lane changelog contract: every release authors exactly 5 English MDX notes; unchanged lane uses exactly `- No package-specific changes.`; sidebar_position computed per lane by scripts/next-changelog-sidebar-position.mjs. The `zfb` lane owns the Rust engine, so zudo-wind notes belong there.
  - Required-check rule: only unconditional jobs may be required. A path-filtered workflow must stay non-required, or use a job-level changed-files detector plus an `if: always()` gate job (docs-checks.yml pattern).
  - Heavy-guard: heavy runs go through `bash $HOME/.claude/scripts/heavy-guard.sh -- <cmd>`; one slot machine-wide; exit 75 means never ran; ENV_SUSPECT means rerun once then defer under a deferred-verification issue, reported as deferred not passed.
  - Worktree policy: children commit locally only, never push; manager pushes from repo root; remove each worktree right after its wave merges.
  - Gate-defining file edits (workflows, nextest.toml, manifest, drift guards) require fresh-context review; never weaken a gate without a linked open issue.
  - All workflow `uses:` lines are pinned to 40-character commit SHAs with a trailing version comment.
