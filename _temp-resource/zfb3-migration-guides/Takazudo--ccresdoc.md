## Risks and open questions

- **Patch strategy is the schedule risk.** The Scope-1 Find/Search hunks were written against Preact-compiled dist; against a zudo-react dist they must be re-authored from scratch. Landing the API upstream during the 6.0.0 window (controlled open/close, host shortcut opt-outs, visible-content walker, icon controls) removes 9 hunks and the harness digest coupling permanently.
- **Closed HTML vocabulary vs. user-authored Markdown.** A single unknown attribute in a user's `CLAUDE.md` raw HTML fails that page's render under zudo-react where 2.x passed it through. The escaper is host-owned Rust and can be hardened before 6.0.0; the corpus test is the only proof.
- **Hand-authored island wrapper** has no 3.1.0 replacement (`persist` lands in the next release); if the target `Z` lacks #3363, the toolbar loses persistence and its history listeners re-arm per navigation — unacceptable for the product, so `Z` must include #3363.
- **Theme variable renames** (17 references) and the `.zd-sidebar-content-wrapper > .flex` utility-name selector depend on 6.0.0's `theme.css`/markup; expect a second pass after #4473.
- **Evidence churn.** Every carrier SHA-256/size and npm integrity changes; `evidence:refresh` must run on each supported platform's binary (`package-facts.json` holds all five), which today is done in CI on linux-x64 plus the macOS host gate.
- **`minimumReleaseAge: 1440`** blocks a same-day install of `Z`/6.0.0 unless every new pin is in `minimumReleaseAgeExclude` (`validate-dependencies.mjs:149-156` enforces the list).
- **Island bundle size**: zudo-react's client runtime is about 2.2× the Preact-era bundle (#3383: 48 KB / 16.6 KB gzip vs 18 KB / 7.4 KB; zfb's measured v3 baseline is ~50 KB raw / 17 KB gzip per shared bundle, https://zfb.takazudomodular.com/concepts/islands/#measured-shared-bundle-baseline); the loopback server makes this a startup, not a network, cost — measure `/assets/islands*.js` in `probe:runtime-package`.
- Open: does 6.0.0 keep `safelist.css` as an export (harmless if unused) or remove it (breaking for `global-css.test.ts`)? Does `zudoDoc()` emit `wind` via `presets` (host adds nothing) or require `zudoDoc({ wind })` (host must forward tokens)? Will `dist/zdtp-loader.js` be self-shielding so Scope 2 can go?
